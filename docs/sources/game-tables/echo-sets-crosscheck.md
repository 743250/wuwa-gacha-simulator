## 结论

- **模拟器套装文案以** `docs/sources/echoes/encore-sets.json` **与** `src/data/echoes.js` **为准**。
- PhantomFetter 保留作官方表交叉核验（BuffIds / AddProp / Priority）。
- 完整 JSON 见同目录 `PhantomFetter.json`。

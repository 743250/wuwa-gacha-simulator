# 弗洛洛 · 官方伤害基数判定（sources 层）

> 日期：2026-07-16  
> 输入：`wiki-html-cache/弗洛洛.html` + `wiki-skill-mults/弗洛洛.json` + 回填后的 `individual/弗洛洛.json`  
> 本文件只记官方事实，不做模拟器取舍。

## 结论

**官方伤害基数 = 攻击（ATK 核），不是最大生命（HP 核）。**

## 证据

1. **技能/共鸣链全文**：无「最大生命」「基于生命」「生命值%伤害」口径。
2. **共鸣解放 · 指挥状态**：正文为「**攻击提升 120%**」。
3. **6 链 · 重世幻象·赫卡忒**：正文为「造成弗洛洛**攻击** 216.4% 的湮灭伤害」。
4. **固有节点属性加成**：攻击提升 / 暴击提升（非生命）。
5. **技能倍率表量级**（Lv10 合计，见 `弗洛洛.json` / skill-multipliers-lv10.md）：
   - 谱曲终末 **660.16%**、永生组歌 **596.43%**、亡与死 **505.01%**、赫卡忒强化约 **330–348%**
   - 与同表 ATK% 主 C 同量级；对照 HP 核卡提希娅 wiki 表最高档约 **90%** 量级，口径不同。
6. **每层余响增加倍率** Lv10 = **82.55%**（绝对百分点加在谱曲终末倍率上，非「生命转换率」）。

### 技能完整描述（官方原文）

**常态攻击 · 生与死的乐章**  
普攻进行最多 3 段的连续攻击，造成湮灭伤害。施放普攻第 3 段时进入重世状态。重击消耗耐力攻击目标，造成湮灭伤害。施放该技能后在一定时间内短按普攻，将会施放普攻第 2 段。谱曲终末：弗洛洛每 25 秒可激活谱曲。同时满足下述 3 种条件时，重击替换为谱曲终末：· 拥有 6 枚【乐声】· 谱曲处于激活状态 · 不处于【定音】状态。施放谱曲终末，消耗耐力，停滞并牵引附近目标，造成湮灭伤害，本次伤害为共鸣技能伤害。每层余响可使本次伤害倍率额外增加。施放此技能时，同时视为施放声骸技能。施放此技能时，谱曲进入冷却状态，随后获得【定音】状态。空中攻击 / 闪避反击略。

**共鸣技能 · 稍纵即逝的梦呓**  
攻击目标，造成湮灭伤害。施放时进入重世状态。

**共鸣解放 · 往日深渊的圆舞曲**  
共鸣能量上限为 0，不消耗共鸣能量。处于【定音】状态时解锁。施放后退出【定音】，进入**指挥状态**，持续 **24 秒**。指挥状态**攻击提升 120%**。弗洛洛漂浮于空中，**指挥赫卡忒**进行战斗，赫卡忒继承弗洛洛属性。登场时可用指令指挥赫卡忒普攻 / 闪避 / 复位 / 谢幕；**赫卡忒受到攻击时弗洛洛会受到伤害**。非登场时赫卡忒不受伤，自动普攻；队伍施放声骸技能时赫卡忒可强化攻击（指挥期间最多 10 次等）。结束指挥时清除所有【乐声】。普攻·赫卡忒两段湮灭（官方视为声骸技能伤害）；强化攻击分弦 / 管 / 彩乐。谢幕多种结束路径，停滞目标造成湮灭伤害。

**固有 · 变音符**  
施放声骸技能时抗打断提升、受伤降低 30% / 15 秒；施放致命组歌、永生组歌、声骸技能时，下一枚【乐声】变为【乐声·彩乐】。

**固有 · 八重奏**  
进入战斗获得 **10 层余响**（退战 4 秒内不可再触发）。每层余响暴击伤害 +2.5%。余响达上限后再获得时，溢出每层暴伤 +1%（最多 +100%），余响清除时一并清除该溢出暴伤。

**变奏 · 致命组歌 / 永生组歌**  
致命组歌：攻击目标，造成湮灭伤害。进入指挥后，下次致命组歌替换为**永生组歌**（停滞目标，共鸣技能伤害）。

**共鸣回路 · 新世界狂想曲**  
- 重世中：地面普攻 → **亡与死的乐章**；地面技能 → **永不消逝的梦呓**（均为共鸣技能伤害口径的派生，施放后退出重世）。  
- **余响**上限 24。官方获取：弗洛洛**不为登场角色**时，赫卡忒强化攻击·弦 / 管 / 彩 可 +1 层；非战斗每 30 秒清全部余响。  
- **乐声**上限 6；普攻第 3 段 / 亡与死 → 弦乐；稍纵即逝 / 永不消逝 → 管乐；定音期间无法获取乐声。

**延奏 · 未完成的曲目**  
下一位登场角色湮灭伤害加深 20%，重击伤害加深 25%，持续 14 秒。指挥中施放延奏时，本次指挥期间切人后赫卡忒额外 2 次强化攻击。

**巧手烹调**（非战斗）略。

## 2. 官方资料分析 · 读懂官方想让她做什么

### 技能逐条读懂

- **乐声 / 谱曲终末 / 定音**：乐声是进核爆的门票。满 6 枚 + 谱曲激活 + 非定音 → 重击变成谱曲终末。谱曲终末吃**全部余响层数**抬倍率，然后进定音——定音的唯一意义是**解锁解放**。
- **余响**：开战送一层「起手弹药」；官方主循环里，余响更多在**指挥期赫卡忒强化**（尤其离场）回流，再喂给**下一轮**谱曲终末。它不是普攻/技能按钮本身叠的条。
- **重世 · 亡与死 / 永不消逝**：动作游戏里的「进重世再按一次」派生。这是**资源期主力输出键**，也是 1 链加厚、6 链挂幻象的挂点——但它们**不是**赫卡忒本体。
- **往日深渊的圆舞曲（解放）**：能量上限 0，门控是定音。施放后**整包换形态**：攻击 +120% + **赫卡忒登场 24 秒**。官方叙事非常清楚——**赫卡忒是指挥状态的一部分，不是常驻召唤、也不是资源期普攻附带物**。
- **指挥中的指令**：登场时玩家「指挥」赫卡忒普攻 / 强化；非登场自动打。承伤规则：登场时赫卡忒挨打 → 弗洛洛也掉血；非登场赫卡忒不受伤。
- **八重奏**：开战 +10 余响 + 每层暴伤，把「第一轮谱曲」的余响底座钉死。

### 6 条共鸣链设计师意图

| 链 | 官方在加什么 | 为什么放在这里 |
|---|---|---|
| 1 | 亡与死 / 永不消逝 +80% | **资源期输出顺滑**：起手与重世键更痛，循环前半不空 |
| 2 | 谱曲倍率与余响加点 +75%，谱曲后 +14 余响 | **核爆与续航**：抬高谱曲终末，并给指挥期 / 下一轮余响底座 |
| 3 | 声骸技能加深 + 彩乐赫卡忒减攻 | **指挥输出与控制**：官方把谱曲 / 赫卡忒多段标成声骸技能伤害，3 链加厚那条线 |
| 4 | 声骸技能时全队全属性 +20% | **团队窗**：官方用声骸技能节点开团增伤 |
| 5 | 指挥领域停滞 + 指挥受伤 -30% | **指挥窗生存与控制** |
| 6 | 强化赫卡忒 +24%；亡与死/永不消逝时重世幻象 216.4% +8 余响；指挥登场/离场双增伤 | **质变**：既抬指挥内赫卡忒，又在重世键上再挂一刀幻象与余响 |

链的排布：**1–2 服务「攒满 → 谱曲」；3–6 大量词条落在「指挥 / 赫卡忒 / 声骸技能节点」**。设计师心中的高潮不在无限普攻叠层，而在**定音后的指挥窗**。

### 官方原版的「重叠风险」（必须读懂再取舍）

官方 6 链字面写的是：施放**亡与死 / 永不消逝期间**召唤重世幻象·赫卡忒。  
而亡与死 / 永不消逝在**资源期与指挥期**都可能出现（重世派生 / 模拟器合并键）。

若模拟器把「幻象」做成与解放相同的**赫卡忒召唤物 / 追击包**，就会出现：

1. 大招前已经「赫卡忒在打」——玩家体感与「赫卡忒随指挥登场」冲突；  
2. **大招包**（协同 / 强化 / 共伤 / 在场）与 **6 链包**（幻象追击）共用同一套「赫卡忒攻击」叙事，职责糊在一起；  
3. 余响在资源期被 6 链 +8 反复灌满，谱曲前与指挥期的资源节奏被打穿。

这是旧设计文档的根因：**没先把「赫卡忒 = 解放指挥包」钉死，就让 6 链直接挂了一套第二赫卡忒。**

### 一句话灵魂

> **弗洛洛是「乐声与余响喂饱谱曲终末 → 定音解锁解放 → 指挥窗里赫卡忒与主人共演」的三阶段 ATK 核湮灭主 C。赫卡忒只在指挥中存在；谱曲终末是进门核爆，指挥是站场高潮。**

## 3. 模拟器取舍设计

### 核心只留一个

**主循环骨架（四步，不可打乱）：**

1. **资源期**：普攻 / 技能攒乐声；余响主要靠开战底座与**上一轮指挥回流** / 链效果，**不靠普攻技能本体叠余响**  
2. **谱曲终末**：满 6 乐声重击替换 → 高倍率核爆 → **消耗全部余响与乐声** → 定音  
3. **解放**：0 AP，定音门控 → **进入指挥，此步才召唤赫卡忒**  
4. **指挥窗（3 回合）**：攻击 +120%；命中触发赫卡忒协同 / 强化；窗尽或切人结束，赫卡忒消散  

### 机制名词归位

| 名词 | 在骨架里的作用 | 模拟器 |
|---|---|---|
| 乐声 | 谱曲门票 | **保留** 0–6 |
| 余响 | 谱曲倍率线性加点 + 每层暴伤 | **保留** 0–24；**谱曲消耗全部** |
| 重世 | 动作派生状态 | **合并**进普攻/技能键，不单独状态机 |
| 亡与死 / 永不消逝 | 资源期主力键；1/6 链挂点 | **保留为按键名与倍率锚** |
| 谱曲终末 | 阶段②核爆 + 定音钥匙 | **保留**，唯一重击形态 |
| 定音 | 解放门控 | **保留**布尔 |
| **指挥状态** | 阶段④整包 | **保留** 3 回合 |
| **赫卡忒** | **指挥包内的召唤与追击** | **仅解放后存在** |
| 弦/管/彩乐 | 强化攻击分支 | **合并**为协同 / 强化两档 |
| 声骸技能伤害 | 官方乘区 | **不做独立类型**（铁律）；归 heavy / 继承本击 |
| 变音符 / 烹饪 / 延奏 | 非战斗或系统未接 | **舍弃**（延奏系统未实装） |
| 谢幕多段结束 | 动作收招 | **合并**为指挥结束清理 |
| 6 链重世幻象 | 官方挂在亡与死/永不消逝上的额外一刀 | **见下节裁定：并入指挥窗，不另开大招前赫卡忒** |

### 设计裁定：赫卡忒包 vs 6 链包（本次重规划的核心）

**裁定 A — 赫卡忒是解放产物，不是常驻单位**

- 只有 `共鸣解放 · 往日深渊的圆舞曲` 召唤赫卡忒。  
- 大招前：无召唤物、无协同、无强化、无共伤。  
- 指挥结束（3 回合尽 / 切人 / 弗洛洛倒下）：赫卡忒消散。  
- 赫卡忒 HP = 召唤时弗洛洛当前 HP；登场共伤（同额、不替挡）；非登场镜像跳过。

**裁定 B — 6 链不得再发明「第二套场外赫卡忒」**

官方 6 链在亡与死 / 永不消逝上挂「重世幻象·赫卡忒」。模拟器为守住「一个核心 + 赫卡忒=指挥包」，做如下折算：

| 6 链官方条目 | 模拟器最终 |
|---|---|
| 强化攻击·赫卡忒 +24% | **保留**，仅指挥内强化追击 |
| 亡与死 / 永不消逝期间重世幻象 216.4% +8 余响 | **仅在指挥状态内**，对普攻键（亡与死）/ 技能键（永不消逝）追加一刀 ATK×216.4% 并 +8 余响；**大招前不触发** |
| 指挥登场湮灭 +60% | **保留**（指挥且登场） |
| 指挥非登场目标受伤 +36% | **保留意图**；若模拟器切人即结束指挥，则本条暂难完整体验，文案仍写明官方意图 |

**为何不 1:1 大招前幻象？**  
因为在 AP 合并键模型下，大招前幻象 = 每次普攻/技能多一次「赫卡忒攻击」叙事 + 余响灌顶，会把阶段①变成假指挥，**和大招包重叠**。模拟器选择：**6 链幻象是指挥窗内的链增幅，不是提前开门的第二赫卡忒。**

**裁定 C — 余响来源（模拟器）**

| 来源 | 层数 | 阶段 |
|---|---|---|
| 固有·八重奏开战 | +10 | 进战一次 |
| 指挥内赫卡忒每次攻击（协同/强化） | +1 | 仅指挥 |
| 2 链 · 谱曲终末结算后 | +14 | 谱曲后（清空后再给） |
| 6 链 · 指挥内重世幻象 | +8 | 仅指挥内普攻/技能 |
| 普攻 / 技能 / 重击 / 变奏本体 | **0** | 永不叠加 |

消耗：谱曲终末按**消耗前层数**结算倍率后**清空全部**；弗洛洛不上场 3 回合后消散。上限恒 24（无指挥期 36）。

**裁定 D — 乐声（模拟器）**

- 开战 +4（加速进第一轮谱曲；官方无开战乐声，属回合制起手折算）  
- 普攻 / 技能 / 重击 / 变奏命中 +1；指挥内赫卡忒追击 +1  
- 满 6 才能谱曲终末；谱曲清空；定音期官方不能获取乐声——模拟器定音很短（立刻可解放），不单独锁乐声获取  

### 招式命名合并

- 普攻按钮名：**亡与死的乐章**（基础普攻段 + 重世派生合并；吃 1 链 +80%）  
- 技能按钮名：**永不消逝的梦呓**（基础技能 + 重世派生合并；吃 1 链 +80%）  
- 重击：仅谱曲终末（无「普通重击」键）  
- 解放：无直伤，只做定音→指挥+召唤  

### 舍弃 / 合并清单

| 官方 | 模拟器 | 理由 |
|---|---|---|
| 重世状态机 | 合并进普攻/技能 | 回合制一键 |
| 弦/管/彩强化三分支 | 协同 ATK×56% / 强化 ATK×340% | 合并同类 |
| 指挥 24 秒 + 指令 UI | 3 回合；弗洛洛出手命中触发追击 | 时间折算 + 无 ACT 指令层 |
| 声骸技能伤害类型 | 谱曲 `heavy`；赫卡忒继承本击 dmgType | 铁律：无 echoSkill |
| 3/4 链「声骸技能时」 | 改为**施放谱曲终末时** | 触发节点对齐实装招式 |
| 官方余响「仅离场强化 +1」 | 指挥内每次赫卡忒攻击 +1 | 回合制要让指挥窗能回流余响 |
| 6 链大招前幻象 | **不做**；幻象锁指挥内 | 防大招包与链包重叠 |
| 延奏 / 变音符 / 烹饪 / 迷梦 | 不做 | 系统或非战斗 |
| 赫卡忒挡刀 | **不做**；共伤同额 | 官方是傀儡受击→主人受伤 |

## 4. 招式数值 · 模拟器版完整设计

### 谱曲终末公式（绝对加点）

`倍率 = (6.6016 × C2基倍) + 余响层数 × (0.30 × C2余响倍)`

- C0–C1：`6.6016 + 余响 × 0.30`  
- C2+：两系数 ×1.75 → `11.5528 + 余响 × 0.525`  
- 结算顺序：**先用当前余响算倍率并造成伤害 → 再清空乐声与余响 → 进定音**；若有 2 链，清空后再 +14 余响  
- 伤害类型：`heavy`（模拟器无声骸技能类型）  
- 3 链：谱曲终末再吃 heavyDmg +80% 乘区  

**与官方差异**：官方表另有按层约 82.55% 的写法；模拟器锁定每层绝对 **+30%**（设计既定，勿擅自改回）。

### 各招完整行为

**普攻 · 亡与死的乐章**  
消耗 1 AP。对主目标造成攻击 ×505%（1 链 ×1.8）湮灭伤害（普攻类型）。命中后乐声 +1。  
- 若**不在指挥**：到此为止。无赫卡忒、无幻象、无余响。  
- 若**在指挥**：另触发赫卡忒协同或强化（见下）；6 链时再追加重世幻象一刀。

**共鸣技能 · 永不消逝的梦呓**  
消耗 1 AP，CD 3 回合。对主目标造成攻击 ×464%（1 链 ×1.8）湮灭伤害（技能类型）。命中后乐声 +1。门控与赫卡忒/幻象规则同普攻（仅指挥内）。

**谱曲终末**  
乐声 = 6 时，重击键替换为本招。消耗 2 AP，CD 1 回合。按上式倍率对主目标造成湮灭范围伤害（重击类型）。**消耗全部 6 枚乐声与全部余响**，进入定音。2 链抬倍率并在清空后 +14 余响；4 链在此时全队全属性伤害 +20% 持续 4 回合。

**共鸣解放 · 往日深渊的圆舞曲**  
仅定音可放，**0 AP**，无直伤。退出定音；进入指挥 3 回合；攻击 +120%；**召唤赫卡忒**（HP=当前生命）。5 链时弗洛洛与赫卡忒同获受伤 -30%。这是整场唯一的赫卡忒登场点。

**指挥内 · 赫卡忒协同 / 强化**  
弗洛洛在指挥中普攻 / 技能 / 重击 / 变奏命中后：赫卡忒攻击主目标。奇数次协同 ATK×56%，每第 2 次强化 ATK×340%（6 链 ×1.24）。每次攻击：乐声 +1、余响 +1。dmgType 继承本击。3 链：强化命中目标攻击 -20% 持续 2 回合。

**6 链 · 重世幻象（模拟器）**  
仅当：6 链 + **指挥中** + 普攻或技能命中。追加 ATK×216.4% 湮灭，余响 +8。不新建第二召唤物，只是指挥窗内的链伤与余响。

**变奏**  
默认致命组歌 ATK×202%、乐声 +1。指挥中替换为永生组歌 ATK×596%。

## 7. 设计边界（bug 防范）

1. **赫卡忒生成点唯一**：仅解放；任何普攻/技能/6 链路径不得 `spawnSummon` 赫卡忒。  
2. **协同 / 幻象双重门控**：必须 `指挥中`；6 链幻象额外要求 chain≥6 且本击为普攻或技能。  
3. **余响与 forte.current**：以 `furoloEchoes` 为准同步 UI；`gainPer* = 0`，禁止通用 `gainForte` 加层。  
4. **谱曲顺序**：倍率用消耗前余响 → 清空 → 2 链再 +14；不可先清空再算伤。  
5. **共伤**：`onOwnerDamaged` 镜像同额后**返回全额**；禁止吸收/overflow 挡刀。  
6. **5 链**：defense 挂弗洛洛与赫卡忒双方，保证共伤后仍同减。  
7. **切人**：结束指挥并移除赫卡忒；启动余响 3 回合不上场消散计数。  
8. **AP**：进指挥前序（2 普攻 + 谱曲 + 解放）常耗尽回合 AP，指挥内第一次普攻须能跨回合；测试勿假定同回合同按。  
9. **定音与再解放**：解放后定音关闭，不能无谱曲连放两枪解放。  
10. **敌人名「赫卡忒」**：日志里 `tgt: 赫卡忒` 可能是敌方单位，不等于我方召唤物已出场——验收以 `battle.summons` 与 mechanic 文案为准。  
11. **文档优先**：改赫卡忒时机 / 余响来源 / 6 链门控前必须改本文件，禁止只改代码。

## 8. 留给讨论的开放问题

1. **指挥中切人是否保留赫卡忒离场输出**（官方非登场赫卡忒自动打 + 6 链 36%）——当前为简化切人即结束指挥；若要做「离场指挥」，需单独开设计，避免与共伤/余响回流冲突。  
2. **开战 +4 乐声**是否改为 +0 更贴官方（会变慢第一轮谱曲）。  
3. **官方余响仅离场强化 +1** vs 模拟器「指挥内每次 +1」是否要再收紧。  
4. **谢幕**是否需要单独一刀 ATK 倍率收招（官方有谢幕伤害）。  
5. **6 链幻象**若未来坚持官方「资源期也可幻象」，只能做成**无召唤物的纯额外伤害 + 余响**，且须重做资源曲线——**不得**再做成提前召唤赫卡忒。

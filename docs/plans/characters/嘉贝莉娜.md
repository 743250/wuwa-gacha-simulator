## 2. 官方资料分析 · 读懂官方想让她做什么

嘉贝莉娜是热熔佩枪限定 5★ 主C。设计师给她一个核心定位：**阈值积蓄→进入恶魔位格→位格内强化动作输出**。她靠「阈限→恶魔位格」双形态切换，在恶魔位格窗口期内打出密集的强化普攻/重击/空中攻击。

### 技能逐条读懂

- **阈限状态**：嘉贝莉娜的默认姿态，在此状态下积累【罪火】和【余火】两种资源。技能/普攻/重击命中均积累资源
- **恶魔位格**：罪火满100时通过恶翼扬升进入的爆发窗口，持续至净炼火耗尽或50秒上限。位格期间全部招式替换为强化版本，替换后的招式消耗净炼火。余火越高位格内伤害越高
- **净炼火**：进入恶魔位格时罪火等值转化，是恶魔位格的弹药，招式命中消耗1点，耗尽则退出位格
- **共鸣解放·炼净**：造成热熔伤害的同时为恶魔位格内的招式提供85%倍率加成。解放是窗口期强化器
- **死运既定（固有·誓猎）**：所有招式命中同一目标后叠加伤害加深，5.5秒内最多4层。限制同类型技能5秒叠1次——确保不同招式轮番命中才能快速叠满
- **延奏·驱猎逐烬**：三段+一段终结的复合伤害，79.5%×3+556.5%，总计795%

### 6 条共鸣链设计师意图分析

| 链 | 位置的设计师意图 |
|---|---|
| 1（不熄抵牾抗争之心） | **余火联动链**：让余火从伤害加深转为暴击伤害加成。强化恶魔位格中余火的价值 |
| 2（行过烈狱与幽暗冥途） | **攻击加成链**：内燃烧组件提供的攻击加成提升350%。常驻增伤 |

| 4（承负无薪孤惧苦火） | **团队增益链**：施放声骸技能时全队同属性伤害+20%。让嘉贝莉娜有团队贡献 |

链的排布逻辑：1-2 链围绕恶魔位格资源利用与常驻增伤，3-5 链分别强化解放/团队/技能三个独立维度，6 链将整个恶魔位格升级为永恒位格并叠加余火联动体系。**所有链指向"让恶魔位格窗口期更强更痛"**。

### 一句话灵魂锁定

> **嘉贝莉娜是"阈限积累→恶魔位格→强化招式倾泻"的阈值窗口型主C。她的循环是普攻/技能攒满罪火与余火，恶翼扬升进入恶魔位格，在窗口期内用强化版炽天猎杀/炼羽裁决/火狱暴雨输出。她的爽点不在于单发数值，而在于进位格后招式全换、节奏变快的形态切换感。**

## 3. 模拟器取舍设计

### 设计思路：阈值是嘉贝莉娜的核心价值

模拟器没有动作游戏的"双形态招式替换/派生树/耐力管理/空中扫射"维度。嘉贝莉娜的双形态切换和派生树在回合制下无法复刻——保留"阈值积累→强化解放爆发"的节奏，舍弃恶魔位格的复杂招式替换体系。

### 保留的核心

1. **猎杀阈值**：普攻/技能/解放积累阈值（0-100），满值时共鸣解放伤害×1.6（6链×2.1）。这是嘉贝莉娜的爆发节奏
2. **共鸣解放·炼净**：对主目标造成atk×400%热熔伤害（副目标200%）
3. **共鸣链加厚输出**：1链暴伤+80%、2链攻击+150%、3链解放伤害+130%、4链全队伤害+20%、5链技能伤害+150%、6链全伤害+60%+阈值增强

### 舍弃/合并清单

| 官方机制 | 模拟器处理 | 理由 |
|---|---|---|
| 阈限/恶魔位格双形态切换 | 合并为阈值增强系统 | 回合制无动作模式切换表达需要 |
| 罪火/余火/净炼火三资源 | 合并为单一猎杀阈值 | 三种资源互通关系在回合制无分层意义 |
| 恶魔位格内招式替换（炽天猎杀/炼羽裁决等） | 不做 | 动作派生体系在回合制无对应 |
| 固有·誓猎（死运既定叠层） | 不做 | 5秒窗口在回合制无表达 |
| 固有·食罪（耐力回复） | 不做 | 耐力系统未实装 |
| 延奏·驱猎逐烬 | 不做 | 延奏系统未实装 |
| 链2内燃烧组织 | 映射为攻击+150% | 回合制无内燃烧概念 |
| 链4官方"施放声骸技能时"触发 | 改为"施放共鸣解放时"触发 | 模拟器无声骸技能类型 |
| 链1/链6免疫打断 | 不做 | 回合制无打断概念 |
| 巧手烹调 | 不做 | 与战斗无关 |

## 7. 设计边界（bug 防范点）

1. **阈值增强范围**：阈值满时只加强共鸣解放伤害×1.6（6链×2.1），不加强其他招式。阈值在解放施放后重置（先判定增强再重置）。同一发解放的 +25 不会自我凑满——增强只对已满阈值的解放生效。
2. **链2攻击+150%为atkUp类型**：atkUp·同源加成取最大值，避免与队伍攻击buff重复叠加。
3. **链4触发条件**：模拟器改为"施放共鸣解放时"触发全队全属性伤害+20%，不绑定声骸技能。buff持续3回合，切人不消失。

### 技能完整描述（官方原文搬运）

**常态攻击 · 质黑相青**：普攻进行最多三段的连续攻击，造成气动伤害。重击消耗耐力攻击目标，造成气动伤害。施放后一定时间内，短按普攻将施放普攻答剑·质黑相青第四段。空中攻击消耗耐力进行空中下落攻击，造成气动伤害。闪避反击成功闪避后，短按普攻将会攻击目标，造成气动伤害，此次伤害视为重击伤害。施放普攻和重击后一定时间内，若受到敌方目标攻击，免疫此次伤害并施放闪避反击，攻击目标并造成气动伤害。

**共鸣技能 · 穿林打叶**：短按共鸣技能，仇远向前突进一段距离，造成气动伤害，此次伤害视为声骸技能伤害。即将受到敌方目标攻击时，施放共鸣技能，免疫此次伤害并停滞周围敌人，此次共鸣技能免疫打断。切换至其他角色时提前清除停滞效果。不辞远长按共鸣技能，仇远向前突进一段距离，对目标造成气动伤害，此次伤害视为声骸技能伤害。按住共鸣技能时，若周围没有目标，仇远会升入空中向前奔袭并持续消耗耐力，奔袭可持续一段时间。在空中时，耐力耗尽或松开共鸣技能将提前结束奔袭，奔袭结束时若周围有目标，会对目标造成气动伤害，此次伤害视为声骸技能伤害。此技能可在空中施放。

**共鸣解放 · 万钧一断**：对范围内的目标造成气动伤害，此次伤害视为声骸技能伤害。仇远暴击高于50%时，每多出1%暴击，施放该技能时，附近队伍中的登场角色提升2%暴击伤害，持续30秒。最高可提升30%暴击伤害。

**固有技能 · 且从容**：进入【淋漓醉墨】状态时，仇远获得且从容效果，持续10秒，该效果每22秒可触发1次。目标受到重击答剑·弦歌不辍、答剑·割股之心、答剑·忠烈死节的伤害提升50%。答剑·忠烈死节在命中目标时，额外回复30点协奏能量。·切换至其他角色时，效果提前结束。

**固有技能 · 与尔同销万古愁**：仇远施放声骸技能时，仇远的竹壶会吸收溢散的能量转化为【金药玉馔】。下次获得【挑灯问剑】时，消耗【金药玉馔】，仇远攻击提升10%，持续20秒。

**变奏技能 · 攻其必救**：攻击目标，造成气动伤害，此次伤害视为重击伤害。施放该技能后一定时间内短按普攻，将施放普攻答剑·质黑相青第三段。

**共鸣回路 · 裁竹为锋**：普攻·答剑·质黑相青【挑灯问剑】达到200点时，普攻替换为普攻答剑·质黑相青，进行最多四段的连续攻击，造成气动伤害，此次伤害视为重击伤害。竹照【挑灯问剑】达到400点时，获得【竹照】效果，附近队伍中的登场角色声骸技能伤害加成提升30%，持续30秒。淋漓醉墨【挑灯问剑】满时，仇远进入【淋漓醉墨】状态，重击替换为重击答剑·割股之心，持续8秒。【淋漓醉墨】状态下，长按普攻可消耗【挑灯问剑】依次施放重击答剑·弦歌不辍、答剑·割股之心、答剑·忠烈死节，造成气动伤害，此伤害视为重击伤害。·施放答剑·弦歌不辍、答剑·割股之心、答剑·忠烈死节时，视为施放声骸技能。·【挑灯问剑】耗尽时，仇远提前退出【淋漓醉墨】

**固有技能 · 巧手烹调**：当前角色烹饪时有概率产出特色料理

## 2. 官方资料分析 · 读懂官方想让她做什么

仇远是气动迅刀限定 5★ 主C。设计师给他一个核心定位：**奏回路三层阈值→淋漓醉墨窗口→答剑三连密集爆发**。

### 技能逐条读懂

- **挑灯问剑（奏回路资源条）**：三个阈值——200点触发普攻第四段派生，400点触发竹照（全队声骸技能伤害+30%），满值时进入淋漓醉墨。这是三级触发的节奏，不止有"满转为开窗"，中间还有两个小里程碑
- **竹照（团队增益）**：400点时触发，全队声骸技能伤害+30%，持续30秒。这让仇远有团队增益价值
- **淋漓醉墨（爆发窗口）**：满值时进入，持续8秒（≈2回合）。窗口内重击替换为答剑三连。这是他的全部伤害来源——窗口内的三连密集输出
- **答剑三连（窗口爆发技）**：弦歌不辍→割股之心→忠烈死节，三段逐段消耗挑灯问剑。且从容+50%全段加成。这是仇远的核心输出模式
- **且从容（第一次窗口强化）**：22秒CD，第一次进入淋漓醉墨获得。答剑三连+50%。忠烈死节命中回复30协奏能量。奖励第一次开窗
- **与尔同销万古愁**：施放声骸技能后攻击+10%。被动增伤
- **共鸣解放·万钧一断**：暴击>50%时每超出1%给登场角色+2%暴伤（上限30%），持续30秒

### 一句话灵魂锁定

> **仇远是"攒挑灯问剑→淋漓醉墨窗口→答剑三连密集爆发"的窗口型主C。他的循环是在窗口内连续三段答剑倾泻所有资源，竹照铺全队增益，且从容让第二窗的每一剑都更痛。他的爽点不在单发数值，而在开窗后三段答剑的密集爆发节奏。**

## 3. 模拟器取舍设计

### 设计思路：S级状态机的必要性

仇远的淋漓醉墨状态+答剑三连序列不是简单的"奏回路满→强化普攻"模型。答剑三连是窗口内的子序列（三段逐段消耗资源），需要状态机管理：进入窗口 → 锁死特定动作模式 → 段数计数 → 资源消耗追踪 → 退出条件。A级工厂的makeSkillLines+标准effect无法表达"窗口内的段数序列"，因此升S级。

### 保留的核心

1. **挑灯问剑（奏回路资源条）**：上限100。普攻+10，共鸣技能+25，共鸣解放+40，变奏+5。满值时进入淋漓醉墨+触发竹照
2. **淋漓醉墨状态**：持续2回合。状态内重击替换为答剑三连（三段合并为一次重击结算，atk×550%气动）
3. **且从容（第一次窗口强化）**：第一次进入淋漓醉墨时触发（每场战斗1次）。答剑三连×1.5。忠烈死节命中+30协奏能量
4. **竹照（团队增益）**：满挑灯问剑时激活，全队全属性伤害+30%（链2额外+30%），持续3回合
5. **共鸣链机制**：1链暴击+20%、3链荷蓑出林+答剑三连+600%+延奏替换、6链退出AOE+暴伤加成

### 舍弃/合并清单

| 官方机制 | 模拟器处理 | 理由 |
|---|---|---|
| 官方三级阈值（200点第四段/400点竹照/满值淋漓醉墨） | 合并为满值一次性触发（竹照+淋漓同触发） | 三级资源管理是ACT节奏感，回合制保留"满值→开窗"单一模型 |
| 答剑三连逐段消耗挑灯问剑 | 合并为一次重击结算（三段合计倍率） | 回合制无法表达逐段消耗资源逐段释放 |
| 且从容10秒/22秒CD | 每场战斗1次 | 22秒≈4回合，回合制下"每场1次"更简洁 |
| 共鸣技能受击反制（免疫伤害+停滞） | 不做 | 回合制无闪避/受击时机概念 |
| 共鸣技能长按不辞远（升空奔袭） | 合并为技能的额外追击 | 动作游戏位移感，回合制无对应 |
| 与尔同销万古愁（声骸技能→攻击+10%） | 不做 | 声骸技能类型在模拟器中无对应 |
| 共鸣解放暴击转暴伤（>50%→2%暴伤/1%） | 保留 | 回合制可表达，暴击百分比动态转换 |
| 延奏·出其不趋 | 保留延奏名，实际效果待延奏系统实装 | 延奏系统暂未实装 |
| 巧手烹调 | 不做 | 与战斗无关 |
| 链3官方20秒CD | 简化为每场1次 | 20秒≈3回合，每场1次更简洁 |
| 链6官方声骸技能伤害类型 | 归为共鸣解放伤害类型 | 模拟器无声骸技能类型 |

## 7. 设计边界（bug 防范点）

1. **切人退出淋漓醉墨**：切人时淋漓醉墨强制结束（官方且从容"切人提前结束"），挑灯问剑保留不重置。
2. **挑灯问剑非当前角色衰减**：战斗中非当前角色时每回合-5点。非战斗中每回合-10点。避免切后台过久直接满资源进场。
3. **答剑三连资源消耗**：施放答剑三连后消耗全部挑灯问剑，退出淋漓醉墨。若资源不足100不可施放答剑三连。
4. **且从容每场1次**：标记`chouyuanCalmUsed`在战斗开始时置false，施放后置true。荷蓑出林进入的淋漓醉墨不触发且从容。
5. **链3荷蓑出林每场1次**：标记`_chouyuanHeSuoUsed`，施放后永久置true。避免无限满资源循环。
6. **链3答剑三连+600%仅生效一次**：标记`_chouyuanC3BoostActive`在荷蓑出林后置true，该次淋漓醉墨结束后置false。不跨窗继承。
7. **链6退出AOE触发时机**：在答剑三连消耗资源退出淋漓醉墨时触发，同时也是在自然退出（2回合到）时触发。每退出一次触发一次。
8. **链6暴伤+100%持续1回合**：施放荷蓑出林时触发，持续到回合结束。切人时效果提前结束。
9. **暴击转暴伤（解放）**：`crate > 0.50`时计算`min(0.30, (crate-0.50)×2)`，只对登场角色生效，持续3回合。暴击不足50%时不触发。

## 8. 留给讨论的开放问题

1. **答剑三连倍率550%是否为最终值**：当前为三段合计估算值，官方各段独立倍率未明确给出。是否需在实装后根据DPAP校准？
2. **且从容冷却每场1次是否太吝啬**：官方22秒CD在实际战斗中约能触发2-3次。是否改为每2次淋漓醉墨可用1次？
3. **荷蓑出林CD简化**：官方20秒CD≈3回合，当前简化为每场1次。是否改为3回合CD更合理？
4. **竹照声骸技能→全属性伤害映射**：官方竹照为"声骸技能伤害加成"，模拟器无声骸技能类型，统一映射为全属性伤害加深。此映射准确吗？
5. **链3延奏替换的新筠坠箨牺牲全队增益**：当前新筠坠箨取代延奏时不再给队友全属性+50%增益，是否合理？

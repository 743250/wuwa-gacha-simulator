### 技能完整描述（官方原文搬运）

**常态攻击 · 祭者独步**：月环·普攻使用月环进行最多3段的连续攻击，造成气动伤害。空中攻击消耗耐力进行空中下落攻击，造成气动伤害。月环·闪避反击成功闪避后一定时间内短按普攻，将会使用月环攻击目标，造成气动伤害。施放该技能后一定时间内短按普攻，将会施放月环·普攻第三段。月弓·普攻尤诺可施放重击·流变·月环，进入月相流转·新月状态，在此状态下尤诺将使用月弓进行攻击。使用月弓进行最多3段的连续攻击，造成气动伤害，此次伤害为共鸣解放伤害。可在空中施放。月弓·闪避反击月相流转·新月状态下，成功闪避后一定时间内短按普攻，将会使用月弓攻击目标，造成气动伤害，此次伤害为共鸣解放伤害。月相流转·新月状态下，施放该技能后一定时间内短按普攻

**共鸣技能 · 先觉赋格**：原初的律动尤诺向前突进，造成气动伤害。告终的喧响尤诺不处于月相流转状态时，施放月环·普攻第3段、变奏技能或原初的律动时，共鸣技能替换为告终的喧响，持续5秒。施放告终的喧响时，造成多段气动伤害，并进入月相流转状态。 未终的喧响尤诺处于月相流转·弦月状态时，共鸣技能替换为未终的喧响。施放未终的喧响时，造成多段气动伤害。告终的喧响与未终的喧响共用同一个冷却时间。越限的弦引尤诺处于月相流转·新月状态时，共鸣技能替换为越限的弦引，初始拥有2次可施放次数。施放越限的弦引时，尤诺进行一次位移，并造成气动伤害，此次伤害为共鸣解放伤害。-技能位移期间可通过移动输入延长位移距离。当尤诺处于受击或被击飞状态中，施放

**共鸣解放 · 溺失月海**：造成气动伤害，并进入月相流转状态。可在空中施放。

**固有技能 · 盈昇**：尤诺每次施放普攻、重击、闪避反击、共鸣技能、共鸣解放、变奏技能时，可获得1个基于自身攻击32%的护盾，持续15秒。该护盾在切换至其他角色时不会继承。

**固有技能 · 新衍**：尤诺施放变奏技能或共鸣解放时，自身可直接获得5层苍白死光的祝颂。

**变奏技能 · 照我以显**：造成气动伤害。

**共鸣回路 · 于盈亏间涨落**：月相流转尤诺可以通过施放共鸣技能·告终的喧响或共鸣解放进入月相流转状态。月相流转分为弦月和新月两种状态，初始默认进入弦月状态，尤诺可以通过施放重击·流变进行两种状态间的切换。处于月相流转状态下：尤诺的跳跃替换为重击·流变；尤诺在空中时无法进行耐力回复；移动时，尤诺会进入漫溯巡游状态，以特殊表现进行移动，在空中时会持续消耗耐力。当触发特定场景交互、探索工具或长按跳跃键时，将退出月相流转状态。月相流转·弦月尤诺使用月环攻击，命中目标时可恢复【灵性】。尤诺可施放重击·流变·月弓，造成气动伤害，此次伤害为共鸣解放伤害，进入月相流转·新月状态。重击·流变·月弓可在空中施放。月相流转·新月尤诺使用月弓攻击

**固有技能 · 巧手烹调**：当前角色烹饪时有概率产出特色料理

**延奏技能 · 晦渡为明**：攻击目标造成100%的气动伤害，下一个登场角色重击伤害加深50%，持续14秒，若切换至其他角色则该效果提前结束。-在施放重击·至臻的完满的过程中施放延奏技能时，不会中断重击·至臻的完满的施放，且延奏技能效果仍然生效。

## 2. 官方资料分析 · 读懂官方想让她做什么

### 技能逐条读懂

尤诺在动作版里是一个**灵性积累 → 月相流转（弦月/新月双形态）→ 满月领域 → 至臻的完满终结**的循环型主C。

- **灵性（奏回路积攒）**：月环攻击（弦月状态）从中恢复。这是她的"积攒器"
- **月相流转（双形态状态）**：弦月（月环，回灵性）/新月（月弓，共鸣解放伤害），通过重击·流变切换。这是她的核心状态
- **满月领域（强化领域）**：灵性积累到阈值后展开，持续20秒。领域内解锁至臻的完满
- **至臻的完满（核心终结技）**：满月领域内的重击终结技。6链倍率+1600%，施放后重击状态
- **苍白死光的祝颂（团队叠层增益）**：变奏/解放给5层，10层时全队全伤害加深

整条循环：普攻/技能积累灵性，满灵性进入月相流转，弦月回灵性，重击切换到新月，越限的弦引输出+叠苍白，满月领域展开，至臻的完满终结，重新积累。

## 3. 模拟器取舍设计

### 设计思路：双形态合并为统一强化状态

官方弦月/新月双形态切换是动作游戏的"派生手感"——弦月回资源、新月打伤害，通过重击切换。回合制没有"切换形态打不同普攻"的交互方式，合并为统一的"月相流转"强化状态：进入后所有攻击强化的灵性持续积累，满灵性展开满月领域解锁至臻的完满。

### 保留的核心

1. **灵性（奏回路资源条）**：上限100。普攻+12（月相流转中+20），共鸣技能+25，变奏+15，解放+40。满值时进入月相流转状态，展开满月领域3回合
2. **月相流转（强化状态）**：持续3回合。期间攻击力+20%（1链+40%），解锁重击·至臻的完满
3. **满月领域**：灵性满值进入月相流转时自动展开，持续3回合。领域内至臻的完满可用
4. **至臻的完满（重击终结技）**：消耗2AP，atk×400%气动。仅满月领域内可用。施放后退出月相流转、清空灵性。6链后倍率+1600%

### 舍弃/合并清单

| 官方机制 | 模拟器处理 | 理由 |
|---|---|---|
| 弦月/满月双形态切换（重击·流光） | 合并为统一月相流转状态 | 回合制无形态切换交互 |
| 4个共鸣技能变体 | 合并为2个：告终的喧响（进入月相流转）和越限的弦引（月相流转中的技能） | 派生合并 |
| 盈昇护盾（每次行动32%ATK） | 合并到月相流转的生存增益中 | 护盾系统成本高 |
| 苍白死光的祝颂叠层系统 | 简化为2链直接触发全队增益 | 叠层过程在回合制下无意义 |
| 延奏重击+50% | 暂舍 | 等延奏系统统一实装 |
| 3链"越限不重置普攻连段" | 舍弃 | 回合制无连段概念 |

## 7. 设计边界（bug 防范点）

1. **灵性切人保留**：奏回路属于角色自身资源，不因切人清空。
2. **月相流转切人保留**：剩余回合数在切回后继续递减。
3. **满月领域同进退**：与月相流转绑定，退出月相流转时同时退出满月领域。

**常态攻击 · 前路领航**:黄灯·普攻召唤啾啾进行三连射击,造成导电伤害。黄灯·加速短按闪避可施放加速,并进入疾奔状态;疾奔状态下自动释放飞星攻击被锁定的敌人,造成导电伤害,此次伤害为普攻伤害。黄灯·下落攻击造成导电伤害。红灯·普攻进行最多3段连续攻击,造成导电伤害。红灯·重击消耗耐力,啾啾和灯灯一同下砸,造成导电伤害,此次伤害为普攻伤害。红灯·下落攻击造成导电伤害。红灯·闪避反击造成导电伤害。

**共鸣技能 · 灯光探照**:前扑黄灯模式期间,共鸣技能转换为前扑,消耗耐力,灯灯朝技能目标位置进行前冲爪击,并切换为红灯模式。灯灯登场时会施放一次不消耗耐力的前扑。后撤红灯模式期间,共鸣技能转换为后撤,消耗耐力,灯灯朝后方撤退,攻击目标,并切换为黄灯模式。黄灯模式期间进行远程攻击,红灯模式期间进行近战攻击。

**共鸣解放 · 啾啾专送**:灯灯将啾啾巨大化之后投掷出去,攻击目标,造成导电伤害。

**固有技能 · 寻路**:红灯模式期间,灯灯导电伤害加成提升10%。

**固有技能 · 奔赴**:施放强化·前扑或强化·后撤时,5秒内灯灯攻击力提升10%。

**变奏技能 · 专项派送**:进入黄灯模式,攻击目标,造成导电伤害。

**共鸣回路 · 信号闪耀**:强化·前扑当【黄灯光能】满时,共鸣技能替换为强化·前扑,造成导电伤害,并进入红灯聚光模式,此次伤害为普攻伤害。红灯聚光模式期间,红灯·普攻和红灯·重击倍率提升,回复的光能增加。施放4次普攻或重击后,退出红灯聚光模式。强化·后撤当【红灯光能】满时,共鸣技能替换为强化·后撤,造成导电伤害,并进入黄灯聚光模式,此次伤害为普攻伤害。黄灯聚光模式期间,飞星替换为强光,造成伤害倍率提升,回复的光能增加。施放6次强光后,退出黄灯聚光模式。强光穿射灯灯施放延奏技能时,消耗当前模式的全部光能。消耗的光能大于等于25点时,可施放强光穿射,造成导电伤害,此次伤害为普攻伤害。

**固有技能 · 巧手烹调**:当前角色烹饪时有概率产出特色料理

**延奏技能 · 护航**:下一位登场角色共鸣技能伤害加深38%,效果持续10秒,若切换至其他角色则该效果提前结束。

## 2. 官方资料分析 · 读懂官方想让她做什么

灯灯是 4★ 导电长刃副 C。设计师给她一个核心定位:**黄灯/红灯双模式 → 光能满时强化前扑/后撤 → 进聚光模式 → 延奏施放强光穿射 → 6 链解放全队攻击 buff**。她本质是"双模式切换 → 资源满爆发 → 全队 buff"的形态切换型副 C。

### 6 条共鸣链设计师意图分析

| 链 | 官方做什么 | 设计师为什么放这里 |
|---|---|---|
| 1(包裹正等待揽收) | 强化后撤后 3 秒回复 60 耐力 | **循环润滑**:1 链是设计师"强化技能应频繁施放"的承诺。模拟器折算为技能伤害 +15%(耐力在回合制对应技能节奏) |
| 2(呜呜物流已收件) | 强化前扑/后撤无视 20% 防御 | **核心招护甲穿透**:2 链让"强化技能"从纯倍率升级为"倍率 + 无视防御"——这是设计师"强化技能应突破护甲"的承诺 |
| 3(特快专递运输中) | 解放啾啾专送 +30% | **解放本体**:3 链在解放上加常驻数值——是设计师"3 链位置数值抬一手"的兑现 |
| 4(灯灯正为您派送) | 普攻伤害 +30% | **普攻核心抬升**:4 链让普攻从工具升级为输出主力——这是设计师"4 链位置核心动作 buff"的兑现。聚光模式期间普攻是主要输出 |
| 5(快件已顺利签收) | 满光能时强光穿射 +100% | **强光穿射天花板**:5 链把"满光能爆发"质变——这是设计师"5 链位置核心招天花板"的兑现 |
| 6(给个五星好评哦) | 解放后全队攻击 +20% 20 秒 | **全队攻击增益**:6 链让她从副 C 升级为团队拐——这是设计师对"6 链质变升级为全队 buff"的标准兑现。20 秒折算 3 回合 |

链的排布逻辑:1-2 链改善强化技能循环和穿透,3 链解放本体,4-5 链抬核心招(普攻/强光穿射),6 链副 C 升级为团队拐。**所有链都围绕"光能 → 强化前扑/后撤 → 解放 → 全队攻击"这一核心**。

### 一句话灵魂锁定

> **灯灯是"切黄灯/红灯模式 → 光能满时强化前扑/后撤 → 进聚光模式打普攻 → 延奏施放强光穿射 → 6 链解放全队攻击 +20%"的导电副C。爽点在光能满那一刻施放强化技能——倍率 ×1.7 + 2 链无视 20% 防御,5 链时强光穿射 +100%,6 链时全队攻击还 +20%。**

## 3. 模拟器取舍设计

### 设计思路:光能条 + 强化技能折算

模拟器没有动作版的"黄灯/红灯双模式实时切换 / 聚光模式触发计数"维度,但**资源条 + 强化技能 + 无视防御** 是回合制天然能表达的。灯灯的光能作为 FORTE gauge(上限 100),满值时强化技能「强化前扑/后撤」×1.7;2 链无视 20% 防御折算为 defPierce 标准 effect;5 链强光穿射 +100% 折算为满光能时强化技能再 +100%;6 链解放后全队攻击 +20%(3 回合)。

### 玩家循环节奏

1. 灯灯上场,普攻 +5 光能 / 共鸣技能(前扑/后撤) +10 / 变奏 +8,3-4 回合内光能满 100
2. 光能满 → 共鸣技能「强化前扑/后撤」(atk × 160% ×1.7,2 链无视 20% 防御,4 链普攻 +30%)
3. 共鸣能量满 → 共鸣解放·啾啾专送(主 atk × 400% / 副 atk × 200%,3 链 +30%)
4. 5 链激活时光能满时强化技能再 +100% 倍率——强化连发爆发
5. 6 链激活时解放施放后全队攻击 +20%(3 回合)——切主 C 上来吃 buff 持续输出
6. 灯灯切下场后,主 C 享受 6 链全队攻击 buff

回合制玩家手感:灯灯是"攒光能 → 满值按强化技能爆发 → 解放啾啾专送 → 6 链全队攻击 +20%"的副 C,**爽点在光能满那一刻按下强化技能——×1.7 + 2 链无视 20% 防御,5 链时还顺手让倍率 +100%,6 链时全队攻击 +20%**。C-Tier 数值最小化,主打"双模式切换 + 强化穿甲"的节奏感。

### 保留的核心

1. **光能(FORTE gauge)**:上限 100,普攻 +10 / 技能 +20 / 解放 +30 积累,满值时强化技能 ×1.7
2. **强化前扑/后撤折算**:光能满时强化技能(共鸣技能本体)倍率 ×1.7
3. **共鸣链组合**:1 链技能 +15%、2 链无视 20% 防御、3 链解放 +30%、4 链普攻 +30%、5 链满光能时强化技能 +100%、6 链解放后全队攻击 +20%

### 舍弃/合并清单

| 官方机制 | 模拟器处理 | 理由 |
|---|---|---|
| 黄灯/红灯双模式实时切换 | 合并到单一 FORTE gauge 光能 | 双模式折算简化 |
| 聚光模式触发计数(4 次普攻 / 6 次强光) | 合并到光能满时强化技能 ×1.7 | 计数器折算简化 |
| 飞星/强光穿射派生 | 合并到强化技能本体 | 派生逻辑折算 |
| 1 链回复 60 耐力 | 折算为技能 +15% | 耐力在回合制对应技能 |
| 5 链满光能时强光穿射 +100% | 折算为满光能时强化技能 +100% | 派生归类到强化技能 |
| 6 链解放后全队攻击 +20% 20 秒 | 折算 3 回合持续 | 时间换算 |
| 延奏护航 38% 加深 | 不做 | 延奏系统暂未实装 |

## 7. 设计边界(bug 防范点)

1. **光能满才可触发强化技能 ×1.7**:强化技能释放时若光能不满 100,只基础倍率 atk × 160%,不触发 ×1.7 加成。
2. **2 链无视防御仅强化版生效**:2 链 defPierce 20% 仅在光能满时强化技能(强化前扑/后撤)生效,非强化版不触发。
3. **5 链 +100% 倍率仅强化版生效**:5 链光能满时强化技能倍率额外 +100%,与 ×1.7 叠加为 ×2.7——保留连发爆发手感。
4. **6 链全队 buff 显式 3 回合**:6 链 teamAtk +20% 在解放释放后施加全队,3 回合后清除——避免 buff 跨窗口残留。

### 切人保留边界

5. **光能切人保留**:光能是灯灯个人 FORTE gauge 资源,切人时数值保留不清零。满 100 触发强化技能 ×1.7 的判定不因切人重置。
6. **2 链无视防御绑本人强化技能**:2 链 defPierce 仅作用于灯灯本人施放的强化技能,切人时 buff 跟随灯灯下场消失,不传播全队。
7. **5 链强化技能 +100% 绑本人**:5 链强化技能 +100% 是灯灯个人 buff,绑定本人强化技能释放,切人时 buff 跟随灯灯下场消失,不传播全队。
8. **4 链普攻 +30% 绑本人**:4 链普攻 +30% 是灯灯个人常驻面板 buff,绑定本人,不传播全队。
9. **6 链全队攻击 buff 切人保留**:6 链全队 +20% 攻击是全队 buff,跟随全队,切人时 buff 保留不消失,持续 3 回合。这是灯灯副 C 身份的灵魂——切下场后 buff 持续让主 C 吃满。

## 8. 留给讨论的开放问题

1. **5 链满光能时强化技能 +100% 折算是否合适**:官方是强光穿射 +100%,模拟器折算到强化技能本体。倾向保留折算版——派生归类让 5 链有玩家感知;若实装后玩家反馈"不像官方"可改为"延奏施放时单独触发强光穿射"。
2. **2 链无视 20% 防御仅强化版生效是否合适**:官方是强化前扑/后撤触发,模拟器保留条件判定。倾向保留条件版——保留"核心招突破护甲"的设计意图;若实装后条件过于严格可放宽到所有技能触发。
3. **6 链全队攻击 buff 3 回合 vs 官方 20 秒(≈3 回合)**:当前 3 回合,与官方折算一致。倾向保留 3 回合——3 回合让 6 链 buff 覆盖整段循环,呼应副 C 团队价值。
4. **延奏护航 38% 加深占位状态**:延奏系统暂未实装,此效果为占位。倾向等待延奏系统实装;若长期未实装可改为"变奏入场后 2 回合内全队技能伤害 +20%"做折算替代。

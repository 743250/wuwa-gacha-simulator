### 技能完整描述(官方原文搬运)

**常态攻击 · 重器藏锋**:普攻进行最多4段连续攻击,造成湮灭伤害。重击消耗耐力攻击目标,造成湮灭伤害。空中攻击、闪避反击造成湮灭伤害。

**共鸣技能 · 磐岩护壁**:展开磐岩护壁,获得护盾,造成湮灭伤害。护盾持续期间受到的伤害由护盾承担。

**共鸣解放 · 不动如山**:攻击目标,造成湮灭伤害,并获得护盾。

**固有技能 · 携攻守阵**:重击发后制人命中目标时,获得【千钧】层数。千钧达到一定层数时,共鸣技能磐岩护壁获得额外护盾量。

**变奏技能 · 风月同天**:出场造成湮灭伤害。

**共鸣回路 · 攻防转换**:满足条件时,长按普攻可施放重击·发后制人。施放后回复桃祈生命值,并对目标造成湮灭伤害。被攻击命中前成功施放重击发后制人,可触发完美防御,免疫此次伤害并反击。

**固有技能 · 巧手烹调**:当前角色烹饪时有概率产出特色料理

**延奏技能 · 千钧**:下一位登场角色伤害加深20%,效果持续10秒,若切换至其他角色则该效果提前结束。

## 2. 官方资料分析 · 读懂官方想让她做什么

桃祈是 4★ 湮灭长刃坦克型辅助。设计师给她一个核心定位:**磐岩护壁护盾 → 重击攻防转换反击 → 6 链护盾期间普攻/重击 +40%**。她本质是"开盾 → 叠守势 → 重击反击→ 6 链输出强化"的坦克型辅助。

### 6 条共鸣链设计师意图分析

| 链 | 官方做什么 | 设计师为什么放这里 |
|---|---|---|
| 1(怀悠然之心) | 攻防转换护盾量 +40% | **入门强化盾**:1 链是设计师"重击反击护盾应更厚"的承诺。模拟器折算为 hp +12% |
| 2(假泯于众人) | 解放暴击 +20% / 暴伤 +20% | **解放稳暴**:2 链让解放从纯盾反升级为"暴击稳定输出"。这是设计师"解放也应稳暴击"的承诺 |
| 3(观万物之细) | 磐岩护壁持续 30 秒 | **护盾延长**:3 链让盾更久。模拟器折算为技能伤害 +20%——回合制无"持续秒数"维度 |
| 4(承负重之担) | 重击发后制人触发时回 25% 生命 + 防御 +50%,15 秒 CD | **重击反击天花板**:4 链是桃祈的灵魂链——重击反击从纯防御升级为"反击 + 回血 + 防御 buff"。模拟器折算为 def +20% 常驻 |
| 5(解市井民忧) | 攻防转换伤害 +50%,命中回 20 能量 | **重击回能天花板**:5 链让重击反击同时回能 + 提升伤害 |
| 6(护城邦安危) | 磐岩护壁期间普攻/重击 +40% | **质变输出**:6 链让她在盾期间不再是纯坦克——这是设计师对"6 链质变"的标准兑现,盾期间输出强化 |

链的排布逻辑:1-3 链强化护盾本体和解放稳重,4-5 链抬重击反击天花板,6 链盾期间输出质变。**所有链都围绕"磐岩护壁 → 重击反击 → 不动如山"这一核心**。

### 一句话灵魂锁定

> **桃祈是"开磐岩护壁护盾 → 重击攻防转换反击回血 → 不动如山释放 → 6 链护盾期间普攻重击 +40%"的湮灭坦克辅助。爽点在重击反击那一下——回血 + 防御 buff,6 链时还顺手让护盾期间所有普攻/重击 +40%。**

## 3. 模拟器取舍设计

### 设计思路:守势条 + 重击反击

模拟器没有动作版的"完美防御窗口 / 护盾精确管理"维度,但**资源条 + 重击反击 + 护盾期间输出强化** 是回合制天然能表达的。桃祈的守势作为 FORTE gauge,满值时重击 ×1.6(攻防转换折算);6 链护盾期间普攻/重击 +40% 折算为常驻普攻/重击加成。

### 玩家循环节奏

1. 桃祈上场,共鸣技能展开磐岩护壁护盾 + 普攻 +8 守势 / 技能 +20 / 解放 +30,3-4 回合内守势满 100
2. 守势满 → 重击·发后制人(atk × 220% ×1.6,4 链 +20% def buff) → 反击同时回血 + 防御 buff(2 回合)
3. 共鸣能量满 + 2 链暴击/暴伤 +20% → 共鸣解放·不动如山(主 atk × 400% / 副 atk × 220%)
4. 6 链激活时磐岩护壁期间普攻/重击 +40%——切主 C 上来吃 buff 持续输出
5. 桃祈继续攒守势等下轮重击反击,期间切换让主 C 享受 6 链普攻 buff

回合制玩家手感:桃祈是"开盾 → 叠守势 → 满值按重击反击 → 解放不动如山 → 6 链护盾期间输出 buff"的坦克型辅助,**爽点在守势满那一刻按下重击——反击回血 + 防御 buff,6 链时护盾期间普攻/重击 +40%**。C-Tier 数值最小化,主打"反击 + 护盾"的节奏感。

### 保留的核心

1. **守势(FORTE gauge)**:上限 100,普攻 +8 / 技能 +20 / 解放 +30 积累,满值时重击 ×1.6(攻防转换)
2. **重击·发后制人**:守势满时强化重击反击,4 链 +20% def buff
3. **共鸣链组合**:1 链 hp +12%、2 链暴击 +10%/暴伤 +20%、3 链技能 +20%、4 链 def +20%、5 链回能 20、6 链护盾期间普攻/重击 +40%

### 舍弃/合并清单

| 官方机制 | 模拟器处理 | 理由 |
|---|---|---|
| 完美防御 / 受击判定窗口 | 合并到守势满时重击 ×1.6 | 折算反击逻辑 |
| 护盾量细分 | 不做(护盾系统暂未实装) | 简化护盾管理 |
| 1 链护盾量 +40% | 折算为 hp +12% | 护盾折算简化 |
| 3 链护盾持续 30 秒 | 折算为技能 +20% | 时间折算 |
| 4 链重击回血 25%+def +50% 15 秒 | 折算为常驻 def +20% | 时间折算 |
| 6 链护盾期间普攻/重击 +40% | 折算为常驻普攻/重击 +40% buff | 护盾状态折算 |
| 延奏千钧 | 不做 | 延奏系统暂未实装 |

## 7. 设计边界(bug 防范点)

1. **守势满才可触发重击 ×1.6**:重击释放时若守势不满 100,只基础倍率,不触发 ×1.6 加成。
2. **6 链普攻/重击 +40% 折算为常驻**:6 链效果折算为常驻面板 buff,不分"是否在护盾期间"——简化判定。
3. **4 链 def +20% buff 显式 2 回合**:4 链防御 buff 在重击释放时施加,2 回合后清除——避免 buff 跨回合残留。
4. **5 链重击回能无 CD**:5 链回 20 能量无 CD,但重击 CD 1 回合自然限流。

### 切人保留边界

5. **守势切人保留**:守势是桃祈个人 FORTE gauge 资源,切人时数值保留不清零。满 100 触发重击 ×1.6 的判定不因切人重置。
6. **4 链 def buff 绑本人**:4 链 def +20% 是桃祈个人 buff,绑定本人 2 回合,切人时 buff 跟随桃祈本人,不传播全队。
7. **6 链普攻/重击 buff 绑本人**:6 链普攻/重击 +40% 是桃祈个人常驻面板 buff,绑定本人,不传播全队。
8. **5 链回能绑桃祈本人**:5 链回 20 能量作用于桃祈本人共鸣能量条,需桃祈本人上场施放重击才回能。

## 8. 留给讨论的开放问题

1. **6 链"护盾期间普攻/重击 +40%"折算为常驻是否合适**:官方是护盾条件 buff,模拟器折算为常驻。倾向保留折算版——护盾系统在回合制无精确管理,折算让 6 链有玩家感知;若实装后玩家反馈"不像官方"可改为"释放磐岩护壁后 3 回合内普攻/重击 +40%"。
2. **4 链 15 秒 CD 折算为 2 回合 buff 是否合适**:官方 15 秒 CD + 5 秒 buff,模拟器折算为 2 回合 buff 无 CD。倾向保留 2 回合 buff——CD 增加复杂度但 buff 时长让玩家有节奏感;若实装后突破平衡可加 CD 3 回合。
3. **2 链暴击 +10% / 暴伤 +20% 在 C-Tier 是否合适**:官方 +20%/+20%,模拟器折算保守。倾向保留 +10%/+20%——C-Tier 不追强度,折算让 2 链有玩家感知;若实装后玩家反馈"不像官方"可改回 +20%/+20%。
4. **延奏千钧全队加深 20% 占位状态**:延奏系统暂未实装,此效果为占位。倾向等待延奏系统实装;若长期未实装可改为"共鸣解放后 2 回合内全队攻击 +15%"做折算替代。

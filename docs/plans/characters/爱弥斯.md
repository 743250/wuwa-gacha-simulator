## 2. 官方资料分析 · 读懂官方想让她做什么

### 技能逐条读懂

- **常态攻击·校准无垠**：四段普攻+二段蓄力重击，重击是核心输出方式模式即刻响应状态状态下快速蓄力是节奏关键。
- **共鸣技能·共赴长航**：核心中的核心——爱弥斯/机兵形态切换。合击·突刺是状态状态桥梁，打自动切形态形成循环。
- **共鸣解放·飞至启明之时**：过载起手爆发→切机兵→开星屑共振（强化光翼共奏和星辉破界（替换终结）。30秒共振+60秒终结窗口。
- **固有·于万籁之前**：即刻响应下击攻击伤害翻3倍——这是设计师"攒资源→即刻响→重击爆发"的节奏承诺。
- **固有·星与星之间**：震谐3层/聚爆2层暴伤叠层，叠满解锁终结伤害加深。
- **变奏·航程伊始的预兆**：入场挂流光增幅，后续解放额外获得共鸣率。
- **共鸣回路·为寂静赋形**：同步率双资源——普攻第4段进窗口→消耗100同效果效率施放光翼共奏（核心爆发）并切形态。震谐/聚爆轨迹是进阶叠加机制。
- **延奏·不可见守候**：退场按模态状态全队增伤。

## 3. 模拟器取舍设计

### 设计思路：震谐/聚爆双模态 + 机兵形态简化

爱弥斯在模拟器中的核心是两个维度的选择：形态和模态。A级工厂下双形态统一为一套招式组，通过模态选择影响倍率和伤害类型。同步率作为核心资源积累满后通过重击或共鸣技能消耗施放光翼共奏爆发。重击（重击型）作为爆发手段保留，即刻响应状态加速蓄力并加深伤害。

### 玩家循环节奏

1. 起手变奏入场 → 获得流光增幅 + 30点同步率
2. 普攻/重击积累同步 + 挂震谐轨迹（震谐模态）或聚爆效应（聚爆模态）
3. 同果效率满100时 → 重击或光翼共奏消耗全部打出爆发
4. 共鸣解放·过载打出AOE爆发 + 进入星屑共振强化后续光翼共奏
5. 星屑共振期间用光翼共奏/终结打出最终爆发
6. 延奏退场根据当式模式模态给全队增伤

### 保留的核心

1. **震谐/聚爆双模态**：出场选择，影响重击/光翼共奏效果
2. **光翼共奏**：消耗同步率的核心爆发技能（视为共鸣解放伤害）
3. **即刻响应→重击爆发**：瞬间响应状态下重击伤害翻倍
4. **共鸣解放两段式**：过载起手+终结收尾
5. **同步率资源管理**：普攻/技能积累→消耗施放爆发

### 舍弃/合并清单

| 官方机制 | 模拟器处理 | 理由 |
|---|---|---|
| 爱弥斯/机兵双形态切换+合击·突刺派生 | 统一为一套招式组，形态差异体现在招式效果中 | 回合制无实时形态切换操作维度 |
| 星屑共振+星辉破界而来双状态 | 合并为解放后强化窗口2回合，期间光翼共奏强化+终结替换 | 双时间窗口在回合制下合为一个buff |
| 震谐/聚爆轨迹多层叠加上限30-60 | 简化为1层标记持续2回合 | 多层轨迹在回合制下过于细粒度 |
| 光增幅状态 | 合并为变奏被动：下1次解放额外获50同步率 | 入场buff简化为触发式效果 |
| 二维电子幽灵保护 | 每场1次致命伤→无敌+全队护盾+满血满能量 | 10分钟CD折算为每场1次 |
| 巧手烹调 | 不做 | 与战斗无关 |

### 各招式完整文字描述

**普攻**：对标目标目标造成 <b class="term-atk">atk × 100%</b> 导电伤害，消耗1AP。积累10点 <b class="term-resource">【同步率】</b>。

**鸣技能 · 共赴长航**：造成 <b class="term-atk">atk × 180%</b> 导电伤害，消耗1AP，CD3。积累25点 <b class="term-resource">【同步率】</b>。震谐模态附加 <b class="term-state">震谐轨迹</b>，聚爆模态附加 <b class="term-state">聚爆效应</b>。

**光翼共奏**：<b class="term-resource">【同步率】</b> ≥100时共鸣技能替换为此招。消耗全同步率对主目标及相邻目标造成 <b class="term-atk">atk × 400%</b> 导电AOE（视为共鸣解放伤害），消耗1AP，CD3。震谐模态额外造成轨迹爆发伤害（层数×atk×50%）；聚爆模态引爆聚爆效应造成 <b class="term-atk">atk × 250%</b> AOE。<b class="term-state">星屑共振</b> 期间此招伤害+50%。

## 7. 设计边界（bug 防范点）

1. **模态切换不可在战斗中切换**：震谐/聚爆在编队时选定，战斗中不可切换。
2. **同步率上限锁定**：上限固定100，超部分不累积，避免溢出。
3. **光翼共奏CD与共鸣技能共享**：两者共享CD3回合，施放光翼共奏后共鸣技能不可用。
4. **即刻响应防重入**多途径获取消置设标志位防止叠加。
5. **震谐轨迹/聚爆效应互斥**：同一目标不能同时携带两种标记，切换模态时清空。
6. **终结施放条件检**：仅星屑共振期间解放替换为终结，结束后恢复过载。
7. **二维电子幽灵每场1次**：触发后标记已使用，退出时清除护盾buff。

### 切人保留边界

1. **同步率角色专属保留**：下保留数值，再次上场读取。
2. **星屑共振计时全局递减**：下场后继续计时，不冻住。
3. **轨迹/效应绑定敌人**：切人不移除，持续伤害仍生效。
4. **即刻响应随下场消失**：下场即移除，再次上场不保留。
5. **光翼共奏同步率不回退**：消耗后清零，施放不打折。

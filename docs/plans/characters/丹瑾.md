## 2. 官方资料分析 · 读懂官方想让她做什么

丹瑾是 4★ 湮灭迅刀副 C。设计师给她一个核心定位：**技能挂朱蚀标记 → 自己叠彤华 → 满彤华触发缭乱爆发 → 6 链全队攻击 buff**。她本质是"挂 enemy debuff + 自身叠层 → 暴击爆发→ 副 C 全队抬一手"的副 C 型角色。

### 技能逐条读懂

- **彤华**：丹瑾的专属资源条。普攻/技能/解放积累,满值时重击·缭乱/纷落释放爆发——回合制折算为 FORTE gauge「彤华」max 100 → enhancedSkill ×1.7
- **朱蚀之刻**：技能命中的敌人 debuff,期间目标受到的湮灭伤害加深。是丹瑾副 C 身份的核心标记
- **重击·缭乱/纷落**：满彤华时释放的高倍率湮灭重击伤害——回合制合并为 enhancedSkill ×1.7
- **4 链彤华 60+ 暴击 +15%**：让玩家在"快满彤华时享受稳暴击",鼓励叠层节奏

### 6 条共鸣链设计师意图分析

| 链 | 官方做什么 | 设计师为什么放这里 |
|---|---|---|
| 1(丹心本如鉴) | 攻击朱蚀目标时自身 atk +5% ×6 层 = +30% | **目标标记激励**：1 链是设计师"先挂朱蚀再输出"节奏的承诺。模拟器折算为攻击 +30% buff |
| 2(明镜却蒙尘) | 攻击朱蚀目标时伤害额外 +20% | **标记伤害收益**：2 链让朱蚀目标吃到双重收益——atk +30% × 伤害 +20% |
| 3(刹那芳华不长久) | 解放伤害 +30% | **解放强化**：3 链是设计师"5 链位置解放本体抬一手"的承诺 |
| 4(孤艳难红) | 彤华 ≥ 60 时暴击 +15% | **叠层激励**：4 链让玩家在叠彤华过程中享受稳暴击——快满彤华时即可享受 |
| 5(剑扫春秋) | 湮灭 +15%,生命低于 60% 额外 +15% | **元素天花板**：5 链是设计师"5 链位置元素伤害天花板"的兑现。模拟器折算为湮灭 +15% |
| 6(绯染碧玉岂堪留) | 重击·缭乱后全队 atk +20%,持续 20 秒 | **副 C 团队价值**：6 链让她从纯爆发副 C 升级为"爆发同时给全队抬一手"——这是设计师对"6 链质变"的标准兑现 |

链的排布逻辑：1-2 链强化朱蚀标记节奏,3 链抬解放,4 链鼓励叠层,5 链元素天花板,6 链副 C 升级为团队拐。**所有链都围绕"朱蚀 → 彤华 → 缭乱爆发 → 全队 buff"这一核心**。

### 一句话灵魂锁定

> **丹瑾是"挂朱蚀标记 → 叠彤华 → 暴击爆发缭乱 → 6 链全队攻击 buff"的湮灭副C。她的爽点在彤华满那一刻按下重击——一记缭乱爆发,6 链时还顺手给全队攻击抬一手。**

## 3. 模拟器取舍设计

### 设计思路：彤华条 → 朱蚀标记 → 缭乱爆发

模拟器没有动作版的"缭乱/纷落双段重击 / 朱蚀之刻目标标记 layer 计数管理"维度,但**资源条 + enemy debuff + 全队 buff** 是回合制天然能表达的。丹瑾的彤华作为 FORTE gauge(上限 100),满值时技能伤害 ×1.7(缭乱/纷落合并折算);1 链朱蚀目标 atk +30%、6 链缭乱后全队 atk +20%。

### 玩家循环节奏

1. 丹瑾上场,共鸣技能命中挂「朱蚀之刻」debuff(敌人受到的湮灭伤害加深,持续 2 回合)
2. 普攻 +6 / 技能 +15 彤华,3-4 回合内彤华满 100 + 共鸣能量满
3. 彤华满 → 共鸣技能伤害 ×1.7(缭乱爆发);4 链彤华 ≥ 60 时暴击 +15%
4. 共鸣能量满 → 共鸣解放「难挽倾颓」(主 atk × 400% / 副 atk × 200%,3 链 +30%) → 配合朱蚀 debuff 加深湮灭伤害
5. 6 链激活时缭乱释放后全队攻击 +20%,持续 3 回合——切主 C 上来吃 buff 持续输出

回合制玩家手感:丹瑾是"挂朱蚀 → 叠彤华 → 满值按缭乱爆发 → 6 链全队 buff"的副 C,**爽点在彤华满那一刻按下重击——一记缭乱爆发同时挂朱蚀加深敌人受到的湮灭伤害,6 链时还顺手给全队攻击抬一手**。B-Tier 数值整体温和,主打"标记 + 爆发"的节奏感。

### 保留的核心

1. **彤华(FORTE gauge)**：上限 100,普攻 +6 / 技能 +15 / 解放 +20 积累,满值时技能伤害 ×1.7
2. **朱蚀之刻 debuff**：技能命中附加,敌人受到的湮灭伤害加深,持续 2 回合
3. **共鸣链组合**：1 链朱蚀目标 atk +30%、2 链朱蚀目标伤害 +20%、3 链解放 +30%、4 链彤华 60+ 暴击 +15%、5 链湮灭 +15%、6 链缭乱后全队 atk +20%

### 舍弃/合并清单

| 官方机制 | 模拟器处理 | 理由 |
|---|---|---|
| 缭乱/纷落双段重击 | 合并到增强技能 ×1.7 | 双段派生在回合制无对应 |
| 1 链朱蚀目标 atk +5% ×6 层 | 折算为 atk +30% 单次 buff | 层数管理折算简化 |
| 5 链生命低于 60% 额外 +15% | 折算为湮灭 +15% 单 buff | 阈值判定折算 |
| 4 链彤华 ≥ 60 触发 | 折算为彤华 ≥ 60 时暴击 +15% | 阈值判定保留 |
| 6 链重击·缭乱触发 | 折算为增强技能(缭乱)释放后触发 | 派生逻辑折算 |
| 延奏朱华流溢 | 不做 | 延奏系统暂未实装 |

## 7. 设计边界(bug 防范点)

1. **彤华满才可触发技能 ×1.7**：共鸣技能释放时若彤华不满 100,只造成基础倍率,不触发缭乱爆发。
2. **朱蚀之刻 debuff 跟随敌人**：朱蚀挂在敌人身上,丹瑾切下场时朱蚀继续存在,但 1/2 链的 atk/伤害加成只丹瑾本人享受——这是副 C 边界。
3. **6 链全队 buff 显式 3 回合**：6 链 teamAtk +20% 在彤华满强化技能释放后施加给全队,3 回合后清除——避免跨窗口残留。
4. **4 链彤华 ≥ 60 暴击 +15%**：4 链暴击 buff 在彤华 ≥ 60 时自动生效,彤华消耗至 < 60 后失效,彤华 ≥ 60 时再次生效——动态判定。

### 切人保留边界

5. **彤华切人保留**：彤华是丹瑾个人 FORTE gauge 资源,切人时数值保留不清零。满 100 触发强化技能的判定不因切人重置。
6. **朱蚀之刻敌人 debuff 切人保留**：朱蚀挂在敌人身上,与丹瑾是否在场无关,2 回合后自动消失。
7. **1/2 链朱蚀目标加成绑丹瑾本人**：1/2 链的 atk +30% 和伤害 +20% 是丹瑾本人攻击朱蚀目标时触发的个人 buff,需丹瑾本人在场施放招式才生效,不传播全队。
8. **6 链全队攻击 buff 切人保留**：6 链全队 +20% 攻击是全队 buff,跟随全队,切人时 buff 保留不消失,持续 3 回合。这是丹瑾副 C 身份的灵魂。
9. **4 链彤华 ≥ 60 暴击 buff 绑本人**：4 链暴击 +15% 是丹瑾个人面板 buff,绑彤华数值,切人时彤华保留则 buff 保留。

## 8. 留给讨论的开放问题

1. **彤华满 → 技能 ×1.7 而非重击 ×1.7 是否合适**：官方缭乱/纷落是重击派生,模拟器合并到强化技能 ×1.7。倾向保留折算版——丹瑾不开重击槽位(B-Tier 简化),折算为强化技能保留"满值爆发"的设计意图;若实装后玩家反馈"不像官方"可改为重击槽位 + 重击 ×1.7。
2. **1 链 6 层 ×5% = +30% 折算为单次 atk +30% 是否合适**：官方是叠 6 层被受伤减层,模拟器折算为单次 buff。倾向保留折算版——叠层管理在回合制增加复杂度,单次 +30% 让 1 链有玩家感知;若实装后玩家反馈"不像官方"可改为叠 3 层 ×10% 还原节奏感。
3. **5 链生命低于 60% 额外湮灭 +15% 折算简化是否合适**：官方双阈值 buff,模拟器折算为常驻 +15%。倾向保留折算版——阈值判定在回合制增加复杂度,常驻 +15% 让 5 链有玩家感知;若实装后突破 DPAP 平衡可改为"生命低于 60% 时叠 +30%"还原。
4. **6 链全队 buff 持续 3 回合 vs 官方 20 秒(≈3 回合)**：当前 3 回合,倾向保留——3 回合让 6 链 buff 覆盖整段循环,呼应副 C 团队价值。

## 2. 官方资料分析 · 读懂官方想让她做什么

### 技能逐条读懂

- **常态攻击**：4段普攻连段、重击操控人偶、空中攻击、闪避反击。普攻不仅是输出，更是绑定缚罪标记的"播种"动作。
- **共鸣技能 · 磁殛咆哮**：这是吟霖最复杂的技能——分两个阶段——先放"磁殛咆哮"进入磁殛状态，状态期间普攻和闪避反击触发"磁殛爆发"攻击所有携带缚罪标记的目标（最多4次）；在一定时间内可释放"召雷磁爆"作为二段技能。共鸣技能本身是一个"窗口机制"——打开一个允许普攻触发额外AOE的窗口，二段可主动收尾。
- **共鸣解放 · 破天雷灭击**：大范围AOE天雷，在官方循环里是"标记传播+爆发"的终结技。
- **共鸣回路 · 千面魅影**：审判值上限100点，由普攻、共鸣技能、变奏入场积攒。满值时重击替换为千面魅影，消耗全部审判值攻击目标。命中缚罪标记目标时，缚罪标记升级为惩罚印记（持续18秒）。惩罚印记承载的目标受到伤害时触发审判之雷进行AOE导电伤害。
- **固有技能**：浸渍痛楚（技能后暴击提升持续5秒）和目标专注（召雷磁爆命中缚罪目标伤害提升、攻击提升持续4秒），两个短时增益。
- **延奏 · 策电**：下一位角色导电伤害加深、解放伤害加深，持续14秒，切人提前结束。典型的副C定位——下场后给队友增益。

### 一句话灵魂锁定

> **吟霖是"打标记→在印记存续期间让队友和自己一起倾泻→用解放收尾"的标记型副 C。她的循环是普攻/技能/变奏积攒审判值,满值自动触发审判之雷给敌人挂上审判印记;印记存续期间吟霖对印记目标伤害抬高(3 链),4 链后全队也获得攻击 buff;在印记叠满前她铺垫,印记爆发时她自己用解放收尾。她的爽点不在连段过程,而在看队友和自己一起对着标记目标倾泻伤害的那一刻。**

## 3. 模拟器取舍设计

### 设计思路：审判印记是吟霖的全部价值

吟霖在动作版里有两层标记体系（缚罪标记→惩罚印记）和复杂的磁殛状态窗口，但核心始终是"给敌人打标记→在印记存续期间吟霖自己与全队对印记目标受益"。模拟器将两层标记合并为单一的「审判印记」体系，将磁殛状态的窗口机制简化为技能直接积攒审判值。印记的"吟霖自己受益"被保留为 3 链每层易伤(仅吟霖自身),4 链后审判之雷触发时再给全队攻击 buff——这是副 C 的本职:让队友吃 buff、自己拿着易伤去收尾。

### 玩家循环节奏

1. 吟霖上场,普攻 1-2 次 + 共鸣技能铺垫,快速积攒审判值至满 100
2. 审判值满 → 自动触发审判之雷,给主目标挂上 1 层审判印记(3 回合)——此为吟霖入场后的第一个 mark 事件
3. 吟霖继续普攻/技能叠印记至 3 层上限,期间 4 链吟霖审判之雷触发时全队攻击 buff 启动(2 回合)
4. 印记满 3 层时按共鸣解放「破天雷灭击」 → 主目标必挂 1 层印记,解放对印记目标伤害 ×2(5 链),作为印记铺设期的收尾爆发
5. 6 链后解放按下后 2 回合内普攻命中印记目标额外触发疾霆昭彰,吟霖不在印铺设期结束就退场,而是继续普攻铺垫疾霆爆发
6. 印记到期或吟霖切下场,印记挂在敌人身上不消失(敌人 debuff),队友继续攻击印记目标受益于 4 链全队 buff,吟霖切回上场时仍可继续叠层

回合制玩家手感:吟霖在场上是"铺垫 → 触发审判之雷 → 解放收尾 → 疾霆主力输出"的节奏型副 C,**爽点不是连段过程,而是印记满后按下解放那一下的全队倾泻数值**。不在场时队友吃 4 链全队攻击 buff 继续打,这是她作为副 C 的本职价值。

### 保留的核心

1. **审判印记**：挂载在敌人身上的标记，上限 3 层，持续 3 回合。吟霖对印记目标输出时受益(3 链每层易伤,仅吟霖自身;4 链审判之雷触发时全队攻击 buff)。
2. **审判值**：吟霖的独立资源系统，上限 100，普攻 +15，共鸣技能 +30，满 100 时自动触发审判之雷给主目标挂 1 层审判印记。
3. **共鸣技能/解放与印记的联动**：1 链对印记目标的技能/解放伤害提升，5 链对印记目标的解放伤害额外提升。
4. **6 链疾霆昭彰**：解放后 2 回合内，普攻命中印记目标额外触发一次技能伤害。

| 舍弃/合并 | 理由 |

## 7. 设计边界（bug 防范点）

1. **审判印记挂载在敌人身上而非角色身上**，因此吟霖切人后退场时印记不会消失，队友可以继续攻击印记目标。印记在每回合 endTurn 中递减（remaining--），归零时删除。
2. **3 链易伤仅吟霖自身受益**：只设置在吟霖自己身上，队友命中印记目标不获得额外加成。
3. **1 链与 5 链叠乘**：两个乘算因子在同一攻击中叠乘，而非加法叠加。
4. **疾霆窗口不递归**：疾霆昭彰造成的伤害不再触发墨鹤追击或任何"命中触发"类效果。每回合 turnCleanup 中重置。
5. **4 链全队 buff 刷新**：每次审判之雷触发或解放时，先清除前一次「前行的鼓舞」buff，再 push 新的，避免叠加。
6. **双资源系统并行**：吟霖同时运行 verdict（审判值）和 forte.current（FORTE）两套系统，填充速率相同（普攻 +15、技能 +30、变奏入场 +15）。FORTE 系统的审判值 effectType 不做实际战斗行为，仅作 UI 标识。
7. **审判值切人保留**：审判值是吟霖个人资源,切人时数值保留不清零,切回来继续累计。满 100 触发审判之雷的判定不因切人重置。
8. **审判印记挂在敌人身上**：印记是敌人 debuff,吟霖切下场时印记继续存在,队友继续攻击印记目标仍能受到 4 链全队攻击 buff——这是吟霖切人后"印记还在飘"的灵魂所在。
9. **3 链易伤仅吟霖自身**：3 链每层 +10% 易伤只挂在吟霖自己身上,队友命中印记目标不获得额外加成。这是副C定位的边界——副 C 给全队 buff(4 链),自己拿着易伤去收尾,不让全队乘同一个易伤易引发数值失控。
10. **6 链疾霆昭彰每回合 1 次**：6 链疾霆窗口内每回合最多触发 1 次疾霆昭彰,避免一次普攻多段判定全触发。

## 8. 留给讨论的开放问题

1. **3 链易伤仅吟霖自身**：3 链每层 +10% 易伤仅吟霖自身享受,不传全队。倾向保留——副 C 给全队 buff(4 链)、自己拿着易伤去收尾,这是设计师对她"副 C 不是半个主 C"的边界。如果实装后发现 3 链数值显得过弱,可改为"吟霖自身易伤 +15%/层",数值加大但不向外传播。

2. **双资源系统(verdict + forte.current)是否合并**：FORTE 的 judgmentMark effectType 不做实际战斗行为仅作 UI 标识,与 verdict 并行填充。倾向合并——保留 verdict 作为唯一战斗资源,FORTE 视觉层挂接到 verdict 的数值即可,避免"两套资源以相同速率跑但只有一套生效"的代码冗余。如果实装时 FORTE 移除涉及 UI 大改,可暂时保留双轨,在 verdict 满 100 触发时同步清零 FORTE。

3. **变奏入场回审判值的折算**：当前折算变奏入场 +15 审判值(官方原文变奏狂雷飓风回复审判值,具体量未给明确数字,折算为与普攻同额)。倾向保留 +15——副 C 切人入场即推进 15% 节奏,正好让"切进来铺垫 → 切出去让主 C 打"的副 C 循环可以压进 5 回合内。如果实装后变奏回值显得过强,可降为 +10。

4. **2 链 refund 触发范围**：官方链文案只说"磁殛爆发命中时"回 5 审判值 + 5 共鸣能量,但代码中普攻/解放命中印记目标也触发 refund。倾向保留宽松版——回合制下"磁殛爆发"作为独立动作不存在,折算为"吟霖任意招式命中印记目标回 5 审判值 + 5 共鸣能量",等于把 2 链从官方的"磁殛爆发专属"扩为"印记命中通用"。这是回合制简化副产物,可保留。

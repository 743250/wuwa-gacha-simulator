## 2. 官方资料分析 · 读懂官方想让她做什么

达妮娅是 3.3 定 S 级热熔主C，设计师给她一个核心定位：**布景形态叠黯核→切换幻灭形态消耗黯核打出终结爆发**。她在布景形态下普攻/技能积累黯核，切换至幻灭形态时消耗黯核让解放伤害暴涨——一个典型的"叠资源→切形态→爆发"循环。

### 技能逐条读懂

- **布景/幻灭双形态**：布景是叠黯核形态（普攻/技能 +1~2 黯核），幻灭是消耗形态（重击切换，解放消耗黯核爆发）
- **黯核**：核心资源，上限 3 层，每层让幻灭形态解放倍率 +150%（官方消耗消耗倍率）
- **熵变强化**：形态切换后的强化 buff，幻灭态攻击+30%，布景态每秒获得虚质粒子
- **蚀域**：幻灭解放后生成的持续 30 秒领域，每 4 秒自动攻击
- **共形能量 / 虚质粒子**：幻灭形态的资源系统，虚质粒子用于强化普攻

## 3. 模拟器取舍设计

### 设计思路：布景叠黯核→切幻灭爆发

模拟器没有蚀域/虚质粒子/共形能量等多层系统，但**布景形态叠黯核→重击切幻灭→幻灭解放消耗黯核爆发**这条核心链用 toggleForm FORTE + 标准 effect 天然能表达。

### 玩家循环节奏

1. 达妮娅布景形态上场，普攻 +1 黯核 / 技能 +2 黯核
2. 黯核 3 层后→重击切换至幻灭形态
3. 共鸣解放·帷幕终景（幻灭形态）消耗所有黯核爆发：atk × 400% ×（1 + 0.3 × 黯核层数）
4. 爆发后变奏切回布景形态继续叠层

### 保留的核心

1. **双形态 toggleForm**：布景（叠黯核）/ 幻灭（消耗黯核爆发）
2. **黯核**：上限 3 层，普攻 +1 / 技能 +2
3. **重击切换形**：布景→幻灭 或 幻灭→布景
4. **幻灭解放**：主 atk × 400% ×（1 + 0.3 × 黯核）/ 副 ×50%

### 舍弃/合并清单

| 官方机制 | 拟器处理 | 理由 |
|---|---|---|
| 熵变强化 / 共形能量 / 虚质粒子 | 不做 | 多层资源系统超出工厂级别 |
| 蚀域（幻灭解放后领域） | 不做 | 持续领域属 ACT 维度 |
| 放逐·幻灭之形 2 段派生 | 合并到技能 | 派生简化 |
| 共鸣模态·聚爆/集谐 | 不做 | 模态系统超出工厂级别 |
| 延奏未竟的谎言 | 不做 | 延奏暂未实装 |
| 声骸技能类触发 | 不做 | 模拟器无声骸技能伤害类型 |

## 7. 设计边界（bug 防范点）

1. **黯核上限 3 层不溢出**：布景形态下黯核已达上限时，普攻/技能不增加黯核数——避免溢出浪费
2. **形态切换只由重击攻击触发**：只有重击按钮可切换形态，解放/技能不触发切换——边界清晰
3. **幻灭形态解放消耗黯核**放解放解放时按当前黯核层数层计算倍率，然后清空黯核——不保留
4. **布景形态解放不消耗黯核**：布景形态解放不触发触黯核消耗——黯核只由幻灭解放消耗
5. **变奏入场保持当前形态**：变奏不改变当前形态——布景入场或幻灭入场维持原形态
6. **黯核 0 层时幻灭解放有基础伤害**：黯核为 0 时幻灭解放仅有基础 atk × 400%（无黯核加成）
7. **3 链黯核满额外触发每场 N 次限制**：黯核满触发的 +1200% 伤害每回合最多触发 1 次

### 切人保留边界

8. **黯核跟随达妮娅本人**：切人时黯核层数保留不清零
9. **形态切人保留**：切人时当前形态保留（布景还是幻景），切回来不变
10. **熵变强化切人不结束**：熵变强化随形态切换持续，不因切人中断

## 8. 留给讨论的开放问题

1. **HP/ATK ≈ 25.9× 却按 ATK 核设计**：达妮娅 JSON 源虽有高 HP/ATK 比例，但官方技能无生命倍率。倾向保留 ATK 核。
2. **黯核叠层节奏是否太慢**：布景形态普攻+1、技能+2，满 3 层需要 2~3 次行动（共 2~3 AP）。倾向保留——这是合理的积累成本；若实装后节奏太慢可改为普攻 +2 / 技能 +3。
3. **双形态切换是否过于简化**：官方布景/幻灭各自有完整普攻 4 段+空中+闪反，模拟器简化为"布景叠黯核 / 幻灭爆发"。倾向保留——这是 A 级工厂的合理抽象；若玩家反馈形态切换感受不足可为两种形态分别设不同普攻特效。
4. **幻灭解放×(1+0.3×黯核)：黯核满 3 层时 ×1.9，叠 5 层时 ×2.5——是否过强**：倾向保留——这是双形态主 C 的核心爆发机制；若实装后突破 DPAP 可降为 ×(1+0.2×黯核)。

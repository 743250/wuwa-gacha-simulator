### 技能完整描述（官方原文搬运）

**常态攻击 · 即兴发挥**：普攻进行最多4段的连续攻击，造成热熔伤害。 重击消耗耐力攻击目标，造成热熔伤害。 空中攻击消耗耐力进行空中下落攻击，造成热熔伤害。 闪避反击成功闪避后一定时间内短按普攻，将会攻击目标，造成热熔伤害。

**共鸣技能 · 激昂变奏**：攻击目标，造成热熔伤害。可与空中攻击构成 chain combo。施放后可施放共鸣技能怒火赋格，造成热熔伤害。

**共鸣解放 · 暴烈终曲**：莫特斐解放浮翼狂想，对范围内的目标造成热熔伤害，期间莫特斐的抗打断能力提升。浮翼狂想浮翼狂想持续期间，队伍中登场角色施放共鸣技能时，莫特斐会进行协同攻击，打出2发共鸣解放加强音，造成热熔伤害。

**固有技能 · 不协和音**：变奏技能不协和音命中目标时，每命中1个目标，回复2点共鸣能量，最多回复6点。

**固有技能 · 持续低音**：共鸣回路浮翼狂想持续期间，共鸣解放加强音命中携带共鸣技能怒火赋格的目标时，造成额外的热熔伤害。

**变奏技能 · 不协和音**：莫特斐出场造成热熔伤害。

**共鸣回路 · 音律叠层**：变奏技能不协和音、共鸣技能激昂变奏、共鸣技能怒火赋格、共鸣解放加强音命中目标时，获得【音律】。普攻第2段、第4段命中目标时，消耗1层【音律】，每消耗1层回复1点共鸣能量。

**固有技能 · 巧手烹调**：当前角色烹饪时有概率产出特色料理

**延奏技能 · 终止和弦**：以技能目标为中心，释放热熔冲击波，对范围内的目标造成莫特斐246.90%攻击的热熔伤害。

## 2. 官方资料分析 · 读懂官方想让她做什么

莫特斐是 4★ 热熔佩枪副 C。设计师给她一个核心定位：**解放铺协同窗口 → 队友用技能时莫特斐补刀加强音**。她不像主 C 自己按键爆发,而像副 C 在后台跟技——窗口期内队友每按一次技能,莫特斐就追两发加强音。

### 技能逐条读懂

- **浮翼狂想**：共鸣解放展开的协同攻击窗口,期间队伍登场角色施放共鸣技能时,莫特斐打出 2 发加强音热熔协同伤害。这是她副 C 身份的全部凭证
- **加强音**：协同攻击招,2 发一次,随队友技能触发。加强音的暴击伤害提升(3 链)、协同数量提升(5 链 4 发降倍率)、伤害提升(1 链 +50%)是链的关键加成方向
- **音律**：普攻 / 技能 / 加强音命中获得,普攻 2/4 段消耗 1 层音律回 1 能量——这是辅助回能工具,加速解放
- **变奏 · 不协和音**：入场招,每命中 1 个目标回 2 能量(最多 6),辅助回能工具

### 6 条共鸣链设计师意图分析

| 链 | 官方做什么 | 设计师为什么放这里 |
|---|---|---|
| 1（孤独的练习曲） | 解放期间队友技能触发加强音 | **协同窗口启动**：1 链是"浮翼狂想期间队友技能触发协同"的核心承诺——这是设计师"副 C 后台跟技"的兑现,让解放窗口的意义显化 |
| 2（虚伪的赞美诗） | 共鸣技能后额外回 10 能量 | **循环回能**：2 链让技能从纯输出工具变为"输出 + 回资源"双轨——这是设计师"副 C 按键节奏不应停下来等能量"的承诺 |
| 3（预热的宣叙调） | 解放期间加强音暴伤 +30% | **协同质量强化**：3 链打磨加强音这一招的伤害天花板——这是设计师"核心辅助招要有质地"的承诺 |
| 4（宣泄的华尔兹） | 解放延长 7 秒 | **窗口延续**：4 链让浮翼狂想窗口持续更久。7 秒折算 1 回合,模拟器折算为解放伤害 +40%——回合制无"持续 7 秒"维度,折算让 4 链有玩家感知 |
| 5（葬送的四重奏） | 技能命中触发 4 发加强音(降 50% 伤害) | **技能触发协同**：5 链让技能本身也能触发协同,数量翻倍但单发伤害折半——这是设计师"5 链数值天花板"放在协同联动上的兑现。模拟器折算为技能伤害 +50% |
| 6（盛怒的无言歌） | 解放时全队攻击 +20%,持续 20 秒 | **全队增益**：6 链让她在副 C / 辅助位有团队价值——解放按下时全队 +20%(3 回合)。这是设计师"6 链质变升级为团队拐"的兑现 |

链的排布逻辑：1 链是协同窗口的启动开关,2-3 链改善循环节奏和加强音质量,4-5 链延长窗口和联动技能,6 链把副 C 升级为团队拐。**所有链都围绕"浮翼狂想 → 加强音协同"这一核心**——没有一条链试图把她变成主 C。

### 一句话灵魂锁定

> **莫特斐是"解放铺浮翼狂想窗口 → 队友技能触发加强音协同 → 满链全队攻击 ↑"的热熔副C。她的爽点在按下解放那一刻——之后切到主C 每按一次技能,莫特斐就从后台追两加强音补刀。**

## 3. 模拟器取舍设计

### 设计思路：浮翼狂想窗口的协同伤害折算

模拟器没有"队友技能触发协同"的实时跟技维度,但解放后的协同爆发可以折算为解放伤害的提升。莫特斐的浮翼狂想作为 FORTE gauge「音律」max 100 → enhancedBurst ×1.5,模拟器用解放倍率 ×1.5 表达"队友技能在窗口内追加强音"的总收益。6 链全队攻击 +20% 保留为副 C 的团队价值。

### 玩家循环节奏

1. 莫特斐上场,普攻 + 律 / 共鸣技能 +律 + 2 链回 10 能量,3-4 回合内音律满 100 + 共鸣能量满
2. 音律满 100 → 共鸣解放「暴烈终曲」(主 atk × 400% / 副 atk × 200% × 音律满 ×1.5,1/3/4 链进一步强化)
3. 解放窗口展开浮翼狂想 3 回合,期间莫特斐切下场,主 C 每按技能时莫特斐从后台追加强音协同(模拟器折算为解放爆发数字)
4. 6 链激活时解放按下立刻给全队攻击 +20%(2 回合),切主 C 上来吃 buff 持续输出
5. 解放窗口结束,莫特斐继续攒音律等下一轮,期间切人让主 C 享受 6 链 buff

回合制玩家手感:莫特斐是"攒音律 → 满值按解放 → 浮翼狂想窗口内主 C 用技能触发加强音 → 6 链全队吃 buff"的后台副 C,**爽点不在于自己按键爆发,而在于按下解放那一刻切主 C 上来——队友每按技能都来自莫特斐的协同伤害**。A-Tier 数值整体温和,主打"后台追技"的辅助体验。

### 保留的核心

1. **音律(FORTE gauge)**：上限 100,普攻/技能/解放积累,满值时解放伤害 ×1.5
2. **浮翼狂想窗口**：共鸣解放展开 3 回合持续 buff,6 链时窗口内全队攻击 +20%
3. **共鸣链组合**：2 链回 10 能量、3 链加强音暴伤 +30%(折算 burstDmg +30%)、4 链窗口延长(折算 burstDmg +40%)、5 链技能协同(折算 skillDmg +50%)

### 舍弃/合并清单

| 官方机制 | 模拟器处理 | 理由 |
|---|---|---|
| 加强音独立 2 发弹道 / 4 发加强音 | 合并为 burstDmg % 加成 | 跟技逻辑在回合制无表达,折算为伤害加成 |
| 4 链浮翼狂想持续 +7 秒 | 折算为 burstDmg +40% | 时间持续在回合制折算简化 |
| 共鸣回路音律回能 / 不协和音回能 | 不做(2 链已折算回能) | 简化辅助回能工具 |
| 空中攻击 chain combo | 不做 | 动作 ACT 派生 |
| 1 链"队友技能时协同 +50%" | 折算为 burstDmg +50% | 跟技逻辑折算 |
| 固有技能不协和音回能 | 不做 | 模拟器辅助回能工具系统简化 |
| 延奏终止和弦 | 不做 | 延奏系统暂未实装 |

## 7. 设计边界(bug 防范点)

1. **音律满才可触发解放倍率 ×1.5**：共鸣解放释放时若音律不满 100,只造成基础倍率伤害,不触发 ×1.5 加成——避免"未满音律也能爆发"。
2. **浮翼狂想窗口持续 3 回合不延长**：窗口回合计数在回合结束时 -1,归零自动退出。不叠加——避免连续解放让窗口永驻。
3. **5 链技能 +50% 不与解放 ×1.5 双算**：5 链 skillDmg 加成只作用于共鸣技能本体,不混入解放倍率计算——边界明确。
4. **6 链全队 buff 显式施加 2 回合**：6 链 teamAtk +20% 在解放施放时一次性施加给全队所有存活角色,2 回合后自动清除——避免 buff 跨窗口残留。
5. **2 链回能每技能一次**：2 链 energyRefund 在每次共鸣技能施放后立即回 10 能量,无 CD——但只有技能 CD 3 回合,自然限流。

### 切人保留边界

6. **音律切人保留**：音律是莫特斐个人 FORTE gauge 资源,切人时数值保留不清零,切回来继续累计。满 100 触发解放 ×1.5 的判定不因切人重置。
7. **浮翼狂想窗口切人跟随**：浮翼狂想窗口是莫特斐个人状态,切人时窗口继续递减(每回合 -1),不因莫特斐下场而暂停。切回莫特斐时若窗口已结束则退出,否则继续。
8. **6 链全队攻击 buff 切人保留**：6 链全队 +20% 攻击是全队 buff,跟随全队,切人时 buff 保留不消失,持续 2 回合。这是莫特斐副 C 身份的灵魂——切下场后 buff 持续让主 C 吃满。
9. **2 链回能绑莫特斐本人**：2 链回 10 能量作用于莫特斐本人共鸣能量条,切人时 buff 标记不残留,需莫特斐本人上场施放技能才能回能。

## 8. 留给讨论的开放问题

1. **4 链"持续 +7 秒"折算为 burstDmg +40% 是否合适**：官方 4 链是窗口时间延长,模拟器折算为解放伤害加成。倾向保留折算版——回合制无"持续秒数"维度,折算让 4 链有玩家感知且不破坏窗口期机制;若实装后玩家反馈"不像官方"可改为"窗口延长 1 回合"还原时间感。
2. **5 链技能协同折算为 skillDmg +50% 是否过强**：官方 5 链是"4 发加强音但伤害降 50%",模拟器折算简化为技能 +50%。倾向保留折算版——回合制无跟技逻辑,折算为技能 +50% 让 5 链成为技能爆发天花板;若实装后突破 DPAP 平衡可改为 +40%。
3. **6 链全队 buff 持续 2 回合 vs 官方 20 秒(≈3 回合)**：当前 2 回合,倾向改为 3 回合对齐官方折算——20 秒折算 3 回合,3 回合让 6 链 buff 覆盖整段浮翼狂想窗口,呼应"副 C 切下场后全队仍吃 buff"的设计意图。
4. **音律积累量普攻 +6 是否过慢**：当前 +6 / 技能 +12,3-4 回合满值。倾向保留——4 回合满值让莫特斐不抢主 C 节奏,与解放能量满值同步;若实装后发现节奏过慢可提为普攻 +8 / 技能 +15。

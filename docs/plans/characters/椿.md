## 2. 官方资料分析 · 读懂官方想让她做什么

### 技能逐条读懂

- **红椿·蕊**：普攻、技能命中时消耗红椿·蕊来提升共鸣能量回复效率。每消耗10点回复4点协奏能量并获1层红椿·蕾（上限10层）。这是椿的"基础资源"——用一格格小资源滚动积累。
- **一日花**：协奏能量充满时，共鸣技能替换为一日花——消耗70协奏能量造成湮灭伤害，进入含苞状态。这是椿进入爆发窗口的入口。
- **含苞状态 · 酣梦**：进入含苞后普攻/技能伤害倍率提升。这是椿的主输出窗口——全招式强化。
- **盛绽状态**：施放共鸣技能后进入，普攻替换为蔓舞（4段追打），共鸣技能替换为黯蕊猎心。这是动作版的连段派生，回合制里无对应。
- **永生花（6链）**：含苞期间协奏再次充满时，共鸣技能替换为永生花——消耗协奏值回复红椿·蕊，造成一日花的伤害，再续含苞并将酣梦倍率大幅提升。6链质变：一窗变两窗。

整条循环读下来：椿是"攒双资源 → 一日花开窗 → 含苞连发 → 6链永生花续窗"的主C。她的设计魂在"协奏充满那一刻触发形态切换"——玩家在战斗中有一个明确的"该爆发了"的信号点。

### 一句话灵魂锁定

> **椿是"攒双资源 → 一日花入场 → 含苞酣梦连发"的形态切换主C。她的爽点在协奏充满那一刻按下技能键——共鸣技能变为一日花，进入含苞状态，三回合内普攻技能全强化。6链把这窗续成两窗：永生花再开一次，酣梦倍率大幅提升。**

## 3. 模拟器取舍设计

### 设计思路：从"普攻翻倍空壳"升级为"双资源→含苞"状态机

旧版模拟器把椿做成FORTE enhancedNormal倍率提升——攒满红椿普攻翻倍、清空、重攒。这是把"双资源+形态切换+6链续窗"全部压成一个数字。本次重做恢复两个核心：双资源触发（红椿·蕊+协奏双门槛）触发永生花进入含苞，以及含苞酣梦窗口期间普攻/技能倍率提升（6链大幅提升）。椿的灵魂（"协奏满那一刻开窗"）完整保留。

### 玩家循环节奏

1. 椿上场,普攻 +10 / 共鸣技能 +15 红椿·蕊,共鸣能量同时积累,4-5 回合内红椿·蕊满 100,协奏能量也接近充满
2. 协奏能量满 → 共鸣技能替换为「一日花」(消耗 70 协奏能量,造成湮灭伤害) → 进入含苞·酣梦状态 3 回合,期间普攻/技能伤害 ×1.5(2 链一日花倍率 +120%、6 链酣梦倍率 +150%/再 +250%)
3. 含苞期间集中按键爆发:普攻 +1 / 共鸣技能 +1,所有伤害都吃酣梦 ×1.5 加成;3 链含苞期间攻击 +58%、4 链全队普攻 +25% 同步生效
4. 含苞 3 回合到期自动退出,或协奏再次充满按 6 链永生花续窗(消耗 50 协奏回 50 红椿·蕊,酣梦倍率提升至 ×3.5+,每场 1 次)
5. 椿继续攒红椿·蕊 + 协奏能量,等下一轮一日花再次开窗;期间可切人让主 C 上来享受 4 链全队普攻 buff

回合制玩家手感:椿是"攒双资源 → 协奏满按一日花开窗 → 含苞期间按键密集爆发 → 6 链永生花续窗"的形态切换主 C,**爽点在协奏充满那一刻按下共鸣技能——技能变为一日花,进入含苞状态,3 回合内普攻技能全强化的瞬间**。不在含苞窗口时她就是攒资源的铺垫期。

### 保留的核心

1. **红椿·蕊（个人资源FORTE）**：上限100，普攻+10/技能+15/解放+30/变奏+20。椿的"基础节奏条"。
2. **永生花形态切换**：红椿·蕊满100且协奏≥50时，共鸣技能替换为永生花。消耗蕊+协奏，造成湮灭伤害，进入含苞回合。
3. **含苞·酣梦**：含苞持续回合期间，普攻/技能伤害倍率提升（6链倍率大幅提升）。3链激活时含苞期间自身攻击提升。
4. **6链永生花续窗**：含苞期间再次满双资源时，可再放一次永生花（每场1次），酣梦倍率大幅提升。

### 舍弃/合并清单

| 官方机制 | 模拟器处理 | 理由 |
|---|---|---|
| 红椿·蕾层数系统（每10蕊得1蕾，10层上限） | 不做 | 第二条个人层数资源违反"一角色一FORTE"原则 |
| 盛绽状态（技能后普攻替换为蔓舞4段） | 不做 | 动作游戏连段替换，回合制无对应维度 |
| 红蕊猎心（盛绽中技能替换二段） | 不做 | 同上 |
| 重击·修枝+5段普攻连段 | 不做 | 椿普攻合并为单段 |
| 一日花vs永生花区分 | 合并 | 模拟器只保留永生花作为"满双资源时的形态切换机" |
| 固有技能·温床（湮灭+15%）/侵占（普攻+15%） | 含入基础倍率 | 被动增益合并到技能倍率体系 |
| 延奏缠绕+一日花后额外伤害 | 不做 | 模拟器无延奏系统 |
| 永生花冷却 | 每场战斗1次 | 回合制简化 |
| 1链一日花免疫打击 | 不做 | 模拟器无打断机制 |

## 7. 设计边界（bug 防范点）

### 切人保留

- **红椿·蕊**：切人时保留，不因切人清空。切回椿时红椿·蕊保持不变。
- **含苞状态**：切人时保留。含苞持续回合在切人期间继续递减（每回合 -1）。切回椿时若含苞已过期则退出，否则继续享受酣梦倍率。
- **3链含苞攻击+58% buff**：绑定在含苞状态上，含苞退出时自动清除。
- **1链变奏暴伤buff**：切人时保留，3回合后自动消失。
- **4链全队普攻buff**：切人后继续生效，2回合后自动消失。

### buff 叠加规则

- 3链含苞攻击+58%是含苞状态内的atkUp buff，与其他atkUp buff同源叠加取最大值。
- 2链永生花+120%是永生花伤害的乘算因子（×2.2），与含苞酣梦倍率叠乘。
- 6链酣梦倍率替代默认倍率，不叠加。
- 含苞酣梦倍率是普攻/技能伤害的乘算因子，与chainEffects的skillDmg/burstDmg加法叠加后再乘算。

### 回合结束时机

- 含苞duration在endTurn的角色turnCleanup阶段递减（与buff duration同步）。
- 红椿·蕊在回合结束时不衰减。
- 永生花续窗CD（每场1次）通过 `_chunYongshengFired` 标志位追踪，不随回合递减。

## 8. 留给讨论的开放问题

1. **协奏门槛 50 是否合适**：模拟器协奏是 per-unit(每个角色自己积累),椿的协奏主要靠普攻/技能命中附带积累。倾向保留 50——50 让玩家在 4-5 回合内能攒满协奏触发一日花,与红椿·蕊满分阶段同步,凑成"双满即开窗"的节奏感。若实装后发现协奏积累太慢拖整体节奏,可降至 30。

2. **永生花倍率 250% 是否合理**：含苞 ×1.5 后 = 375%,6 链 ×2.5 = 625%,2 链 +120% = 1375%。倾向保留——这是 6 链质变的合理天花板,6 链椿就该比 0 链强一档。若实装后突破 DPAP 平衡,可把永生花基础倍率从 250% 降至 200%。

3. **6 链续窗"每场 1 次"是否合理**：若战斗较长(深塔 BOSS 战)可放宽至每场 2 次。倾向保留每场 1 次——6 链永生花是"含苞一窗续成两窗"的质变兑现,每场 1 次让玩家在长战斗中精心选择续窗时机;放宽到每场 2 次会让数值过于持续而丢失节奏对比感。

4. **含苞期间解放是否享受酣梦倍率**：官方"酣梦"列表中不包含共鸣解放。倾向"含苞期间解放不享受酣梦倍率"——解放是独立终结技,酣梦是窗口期普攻技能强化,两者节奏不同;若解放也享受酣梦倍率会让含苞 3 回合内成为"任意按键都质变"的失控窗口。这是官方列表的明确边界,应保留。

5. **永生花是否走共鸣技能 CD**：永生花消耗 1 AP 但不走技能 CD 3 回合。倾向保留永生花不走技能 CD——永生花是含苞期间再次满双资源触发的"续窗招",不是常规技能;若挂 CD 3 回合会让续窗节奏被打断,失去"6 链质变"的灵魂。若实装后永生花使用频次过高可改为单 CD 2 回合。

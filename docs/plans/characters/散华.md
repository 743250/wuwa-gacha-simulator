### 技能完整描述（官方原文 · encore）

**常态攻击 · 寒光**：普攻进行最多 5 段的连续攻击，造成冷凝伤害。重击消耗耐力发动攻击，造成冷凝伤害。空中攻击消耗耐力进行空中下落攻击，造成冷凝伤害。闪避反击成功闪避后一定时间内短按普攻，将会攻击目标，造成冷凝伤害。

**共鸣技能 · 朔雪永冻**：造成冷凝伤害，剑气会留下 1 道【冰棱】。

**共鸣解放 · 焦瞑冻土**：造成冷凝伤害，并形成 1 道【冰川】。

**固有技能 · 凝冰**：施放变奏技能时，散华的共鸣技能伤害提升 20%，持续 8 秒。

**固有技能 · 瀑雪**：施放第 5 段普攻后，散华共鸣回路冰绽造成的伤害提升 20%，持续 8 秒。

**变奏技能 · 凛刺**：挥刀坠击，造成冷凝伤害，留下 1 道【冰棘】。

**共鸣回路 · 无明心音**：重击·爆裂——按住普攻时指针移动，若指针在【冰痕】区域时松开普攻，散华将施放重击爆裂攻击目标，造成冷凝伤害，此次伤害为重击伤害。冰绽——重击爆裂会引爆攻击范围内的【冰棘】、【冰棱】和【冰川】，造成冷凝伤害，冰绽造成的伤害为共鸣技能伤害。冰痕区域扩大规则——每拥有 1 层【透视】都会扩大【冰痕】区域，最多可拥有 2 层【透视】。施放第 5 段普攻时获得 1 层【透视】；施放变奏·凛刺时获得 1 层；施放共鸣技能·朔雪永冻时获得 1 层；施放共鸣解放·焦瞑冻土时获得 2 层；施放重击爆裂时移除所有【透视】。

**延奏技能 · 凛絜**：下一位登场角色普攻伤害加深 38%，效果持续 14 秒，若切换至其他角色则该效果提前结束。

## 2. 官方资料分析 · 读懂官方想让她做什么

散华是 4★ 冷凝迅刀。encore 回路名「无明心音」把她的战场拆成三件套：

1. **冰造物**：冰棘（变奏留下）/ 冰棱（技能留下）/ 冰川（解放形成）—— 场上的“可引爆物”
2. **透视 + 冰痕**：用第 5 段普攻 / 技能 / 变奏 / 解放叠透视，扩大重击爆裂的判定区
3. **重击·爆裂 / 冰绽**：在冰痕区内松手 → 引爆范围内全部冰造物

她不是“站场普攻主 C”，而是 **短站铺冰 → 一记爆裂引爆 → 延奏把普攻加深交给下一位**。6 链进一步把“引爆”变成全队攻击拐，坐实副 C。

### 技能逐条读懂

- **寒光（普攻 5 段）**：铺垫与叠透视的主手段；第 5 段是 1 链暴击窗 + 固有瀑雪的钥匙
- **朔雪永冻**：伤害 + 留下冰棱；在模拟器里 = 快速灌冰棘 + 技能伤害本体
- **焦瞑冻土**：伤害 + 形成冰川；4 链把“解放 → 下次爆裂”焊成标准连招
- **无明心音**：真正的核心。爆裂是重击伤害；冰绽引爆是共鸣技能伤害标签——模拟器不拆双标签，统一为「满冰棘强化重击」
- **凛刺（变奏）**：入场即留冰棘，副 C 切人即启动
- **凛絜（延奏）**：下一位普攻加深 38% · 14s——官方给的副 C 交棒工具，旧设计文档写“延奏未实装”已过时，本版**保留**

### 6 条共鸣链设计师意图

| 链 | 官方做什么 | 设计师为什么放这里 |
|---|---|---|
| 1 孤身孑然 | 第 5 段普攻 → 自身暴击 +15% · 10s | **节奏窗**：奖励“打满第五段”的入场/铺垫动作，不是常驻暴击 |
| 2 净雪明心 | 爆裂耐力 −10；技能抗打断 5s | **润滑核心键**：让爆裂更好按出去；抗打断在回合制无对应 |
| 3 目视异常 | 对生命 &lt;70% 目标伤害 +35% | **收割乘区**：条件伤害，不是白板 allDmg |
| 4 剑修五蕴 | 解放回 10 能量 + 5s 内下次爆裂 +120% | **灵魂连招**：解放不是终点，是“下一记爆裂”的发令枪 |
| 5 颠覆无常 | **冰绽**暴伤 +100%；造物消失也炸 | **只厚引爆**：质变落在回路引爆，不是散华全身暴伤面板 |
| 6 曙色天光 | 引爆冰棱/冰川 → 全队攻 +10% · 20s · 叠 2 | **副 C 毕业**：引爆 = 拐；要叠层，不是一次 +20% 糊弄 |

排布：1–3 改善铺垫与条件输出 → 4 焊死解放→爆裂 → 5 只抬引爆暴伤 → 6 引爆变全队拐。**没有一条链要把她改成站场主 C。**

### 一句话灵魂锁定

> **散华是「普攻/技能灌冰棘 → 满条重击·爆裂一键引爆 → 延奏把普攻加深交给下一位」的冷凝副 C；4 链把解放焊成爆裂的发令枪，6 链让引爆本身变成全队攻击拐。爽点在冰棘满格按下爆裂的那一下。**

## 3. 模拟器取舍设计

### 设计思路：一条冰棘条 = 全部冰造物 + 透视

动作版的冰棘/冰棱/冰川 + 透视层数在 AP 回合制里拆成多状态机成本过高，且 4★ 不值得 S 级专属文件。

**合并规则**：

| 官方 | 模拟器 |
|---|---|
| 冰棘 / 冰棱 / 冰川 | 统一为 FORTE **冰棘** gauge（0–100） |
| 透视叠层扩大冰痕 | 不建模；用“满 100 才能放爆裂”代替“指针进区” |
| 重击·爆裂 + 冰绽双段 | **一次**强化重击结算；倍率对齐 wiki 爆裂 ≈ 370% |
| 普通重击（未满条） | **不提供**：未满条重击按钮不可用（或灰显），避免无意义的 111% 废键 |
| 延奏凛絜 | **保留**：切出时给下一位登场者普攻伤害加深 |

### 玩家循环节奏

1. 变奏·凛刺入场（+15 冰棘）→ 普攻 / 技能灌条（约 3–4 AP 周期内满 100）
2. 可选：能量满时先放**焦瞑冻土**（4 链则回 10 能量 + 挂「下次爆裂 +120%」窗）
3. 冰棘满 → **重击·爆裂**（2 AP）：打出爆裂倍率，**清空冰棘**；6 链叠全队攻
4. **切换** → 延奏凛絜给下一位普攻加深 38% · 2 回合；主 C 吃 6 链攻 buff 输出
5. 散华再入场重复灌条

手感一句话：**短站铺满 → 一键爆裂 → 交棒**。不是站场 6 回合普攻机。

### 保留的核心

1. **冰棘 FORTE**：上限 100；满值才允许重击·爆裂；爆裂后清空
2. **重击·爆裂**：核心爆发键；吃 2/4/5 链乘区
3. **解放 → 爆裂窗口（4 链）**：回能 + 下次爆裂大额增伤
4. **引爆全队攻（6 链）**：叠层拐
5. **延奏凛絜**：副 C 交棒

### 舍弃 / 合并清单

| 官方机制 | 模拟器处理 | 理由 |
|---|---|---|
| 冰棘→冰棱→冰川三造物 | 合并为冰棘 gauge | 一核心一条资源 |
| 透视 / 冰痕指针 | 满条才能爆裂 | 回合制无“按住松手” |
| 冰绽独立伤害段（技能标签） | 并入爆裂一次结算 | 避免双段结算膨胀 |
| 普通重击 111% | 不做 | 满条才是她的重击 |
| 2 链耐力 −10 / 抗打断 | 折 **重击伤害 +20%** 常驻 | 耐力/硬直无对应 |
| 5 链“消失也爆炸” | 不做独立过期炸 | 用“爆裂必清空并结算”覆盖；暴伤只加在爆裂上 |
| 固有凝冰 / 瀑雪 | 不单独做 | 凝冰并进变奏节奏叙事；瀑雪并进 1 链第五段窗 |
| 空中 / 闪避反击 | 不做 | 动作专属 |

### 相对旧版设计的纠偏（为何重写）

| 旧版问题 | 本版 |
|---|---|
| 技能名混用「霜歌凌华 / 凝霜归涉」 | 统一 encore：**寒光 / 凛刺** |
| 冰棘满不消耗、可无限 ×1.8 | **爆裂清空冰棘**；强化写进重击基底，不再另乘裸 1.8 与文案双轨 |

## 5. 共鸣链 · 模拟器版完整设计

> 文案只写**当前模拟器效果**，不写“官方原版 / 未实装 / 折算说明”。工程备注可写在 §7。

### 1 链 · 孤身孑然

散华每施放第 **5** 次普攻时，自身暴击提升 **15%**，持续 **2** 回合。

- effect 意向：`sanhuaC1`（trigger · 第 5 次普攻 → 自身 `crateUp` 0.15 · 2 回合）
- ❌ 禁止：常驻 `crate +15%`

### 2 链 · 净雪明心

散华的重击伤害提升 **20%**。

- effect：`heavyDmg` 0.2（耐力/抗打断的回合制等价）
- 官方“只对爆裂降耐力”→ 模拟器仅存在爆裂这一种重击，故等同爆裂 +20%

### 3 链 · 目视异常

散华攻击生命低于 **70%** 的目标时，造成的伤害提升 **35%**。

- effect 意向：`sanhuaC3` / 条件 `hpBelow: 0.7` → `allDmg` +0.35（仅对符合条件的目标）
- ❌ 禁止：无条件 `allDmg +20%` 冒充

### 4 链 · 剑修五蕴

施放共鸣解放·焦瞑冻土时，回复 **10** 点共鸣能量；并在 **2** 回合内，使下一次重击·爆裂造成的伤害提升 **120%**。

- effect 意向：`sanhuaC4`（burst → energy +10；挂 `nextBurstHeavy` / `sanhuaNextBaolie` value 1.2 · dur 2 · 爆裂命中后清除）
- ❌ 禁止：常驻 `heavyDmg +50%` 或把 +120% 写成永久重击加成

### 5 链 · 颠覆无常

重击·爆裂的暴击伤害提升 **100%**。

- effect 意向：`sanhuaC5`（仅 `dmgType === 'heavy'` 且本次为爆裂时 `cdmg +1.0`）
- ❌ 禁止：面板常驻 `cdmg +100%`
- 官方“消失也爆炸”：不另做；爆裂清空冰棘即唯一引爆点

### 6 链 · 曙色天光

施放重击·爆裂后，队伍中的角色攻击提升 **10%**，持续 **3** 回合，可叠加 **2** 层。

- effect 意向：`sanhuaC6`（爆裂成功 → 全队 `atkUp` 0.10 · stack 2 · dur 3 · src `曙色天光`）
- ❌ 禁止：一次固定 `teamAtk +20%` 且不叠层

## 7. 设计边界（bug 防范点）

1. **未满冰棘不能爆裂**：按钮禁用；禁止静默打出普通重击 111%。
2. **爆裂必须清空冰棘**：禁止旧版“满条常驻 ×1.8 还不扣条”。
3. **4 链是次数窗不是常驻**：只强化**下一次**爆裂；未在 2 回合内打出则过期；禁止写成永久 heavyDmg。
4. **5 链只厚爆裂暴伤**：普攻/技能/解放不吃这 +100% 暴伤。
5. **6 链叠层上限 2**：同源 buff 叠层刷新，禁止无脑 +20% 单层冒充。
6. **3 链看目标当前 HP**：按结算瞬间 `hp/hpMax < 0.7`；治疗抬回 70% 以上后不再享受。
7. **冰棘切人保留**：个人 gauge，切出不清零。
8. **1 链计数与暴击窗绑本人**：切出带走；不给队友暴击。
9. **4 链窗绑本人**：切出可保留在散华 unit 上，但只有她自己的下次爆裂能吃到。
10. **6 链全队攻 / 凛絜**：切人保留（全队 buff / 延奏给下一位）；凛絜不与 6 链攻混成同一 buff。
11. **爆裂默认单体主目标**：不做全场秒杀 AOE；若日后要做“相邻副目标”，另开设计，不在本版默认。
12. **registry / skillHints / 本文件数字必须一致**；禁止 tooltip 写 +120% 而 effect 仍是 +0.5 常驻。

## 2. 官方资料分析·读懂官方想让她做什么

### 技能逐条读懂

- **可塑晶质与灵萃**：珂莱塔身上持有可塑晶质时普攻替换为必要性手段（消耗晶质追打）；灵萃通过技能积累，满时重击替换为限制性策略（消耗灵萃，减少暴力美学CD）。这是双资源层叠——一层管普攻派生、一层管重击爆发。
- **暴力美学到示我璀璨**：共鸣技能起手给敌人附加变彩（定身），随后施放二段示我璀璨——消耗所有可塑晶质造成爆发伤害。这是一套"定住后收割"的节奏。
- **枪花轮舞**：共鸣解放进入的特殊状态，普攻或共鸣键变为施放死兆（点射+4枚晶体），每发死兆获得1点镜向箔，满4点可施放致死以终——全屏大爆炸。枪花轮舞是"持续小型爆发积累到最终大招"的窗口。
- **解离**：珂莱塔的攻击给目标附加解离效果，攻击解离目标时忽视防御。这是一个常驻增伤机制，贯穿她的所有攻击。
- **重击·末路见行**：灵萃满且镀色晶激活时，长按普攻消耗灵萃打出重击，减少暴力美学CD。这是她资源闭环的"泄能"点。

## 3. 模拟器取舍设计

### 设计思路：晶体层叠是珂莱塔的核心节奏

模拟器没有枪花轮舞窗口的"连续点击死兆"操作，但资源层层积累到满然后释放强化版技能是回合制天然能表达的。珂莱塔在模拟器里保留了"叠晶体到技能爆发到重击泄能到解放两段"的节奏感，将官方四种资源（可塑晶质/灵萃/镀色晶/镜向箔）合并为一条FORTE stacks。

### 玩家循环节奏

1. 珂莱塔上场,普攻 +1 / 共鸣技能 +1-3 灵萃层,4-5 回合内灵萃满 5 层,期间共鸣技能命中给敌人附加解离 debuff 2 回合
2. 灵萃满 → 共鸣技能倍率 ×1.5(强化示我璀璨),同时对解离目标暴击 +12.5%(1 链作为面板常驻已是基础)
3. 灵萃满 → 重击「末路见行」(消耗 5 层灵萃) → 高倍率重击,共鸣技能暴力美学 CD -1 回合;4 链重击后全队共鸣技能伤害 +25%(3 回合)
4. 解放「致死以终」(3 AP) → 主目标 burst 主 400% × (1+2链 126%),副目标 burst 副 200% × (1+6链 186.6%) × FORTE_BOOST;主目标段必挂解离 debuff
5. 解放爆发完毕,返回铺垫期——继续灵萃积累等下轮重击泄能与解放

回合制玩家手感:珂莱塔是"攒灵萃 → 满层按重击末路见行泄能 → 解放两段爆发(致死以终主目标+死兆副目标)"的连发型主 C,**爽点在灵萃满那一刻按下重击的瞬间,以及解放时主目标致死以终+副目标死兆两段伤害同时飘起的全屏数字**。不在灵萃积累期时她就是攒资源的铺垫期。

### 保留的核心

1. **灵萃（FORTE stacks）**：上限5层，命中+1~3层，满层后共鸣技能倍率提升（6链FORTE_BOOST进一步提升），并可释放重击·末路见行。
2. **解离 debuff**：共鸣技能命中附加，持续2回合，对解离目标暴击提升（1链效果作面板常驻）。
3. **重击·末路见行**：有重击槽位，消耗灵萃打出高倍率并缩减技能CD。
4. **共鸣解放双段**：主目标致死以终+副目标死兆，两段独立计算加成。

### 舍弃/合并清单

| 官方机制 | 模拟器处理 | 理由 |
|---|---|---|
| 可塑晶质/灵萃/镀色晶/揭幕者四类资源 | 合并为FORTE stacks单条 | 资源条数量过多 |
| 枪花轮舞状态+死兆4次到致死以终 | 合并为共鸣解放主+副双段一次结算 | 回合制变招按钮没必要保留 |
| 必要性手段/限制性策略/礼节性问候 | 不做 | 动作游戏连段派生 |
| 变彩/焕彩 debuff（行动锁定） | 不做 | 回合制无对应 |
| 重击限制性策略 | 合并到末路见行 | 空槽位 |
| 镜向箔计数 | 不做 | 已合并为解放主副双段 |
| 3链延奏碎璃镜花1032.18% | 合并到skillDmg+93% | 延奏未实装 |

**变奏·入冬叹调**：消耗0 AP，切人入场时对主目标造成攻击力80%的冷凝伤害，命中时灵萃+2并为目标附加解离2回合。

## 7. 设计边界（bug 防范点）

1. **灵萃满5层才可放重击·末路见行**：未满时重击按钮禁用。
2. **重击清空灵萃后暴力美学CD-1回合**：进turnCleanup时优先处理buff/debuff清理再处理CD递减。
3. **共鸣解放分段结算**：主目标段（致死以终）走burst主400%，2链+126%生效；副目标段（死兆）走burst副200%，6链+186.6%和FORTE_BOOST生效。两段独立叠加加成。
4. **解离 debuff 跟随敌人**：不随珂莱塔切下场而中断，在其他角色攻击时保留但仅珂莱塔享受暴击增益。
5. **4链全队buff持续2回合、切人不消失**：buff跟随全队，不随珂莱塔切下场。
6. **灵萃切人保留**：灵萃是珂莱塔个人 FORTE 层数资源,切人时层数保留不清零,切回来继续累计。满 5 层触发重击末路见行的判定不因切人重置。
7. **解离 debuff 是敌人减益**：解离挂在敌人身上,珂莱塔切下场时解离继续存在,但仅珂莱塔本人在场时享受暴击增益——这是设计师对"标记是我打的、增伤是我享受的"的副 C 边界,不应让全队暴击触发。
8. **重击末路见行 CD 缩减绑定本人**：重击末路见行施放后,共鸣技能暴力美学 CD -1 回合——这是珂莱塔个人 buff,切人时 CD 缩减效果跟随珂莱塔本人,不传播全队。

## 8. 留给讨论的开放问题

1. **6 链死兆段 +186.6% 与死兆晶体翻倍是"两件事合一数"**：模拟器是否需要保留"晶体翻倍"的视觉感(如额外一次副目标伤害)?或合并为单倍率加成保持简单? 倾向合并为单倍率加成——晶体翻倍在动作版是视觉叙事(玩家看见 8 枚晶体飞出),回合制下无视觉落点,折算为"死兆副目标段额外打一次 ×0.5 倍率"会让数值链路复杂化。合并为 ×2.87 倍率加成后,玩家心智模型就是"6 链死兆爆发更狠",清晰直观。

2. **解离暴击增益目前是常驻(1 链即生效)**：是否需要改为"解离期间才生效"的条件式以贴近官方节奏? 倾向改为条件式——官方 1 链"对解离目标暴击 +12.5%"是玩家先打解离再收益,这是设计师"先挂标记再输出"的节奏鼓励;若常驻会让 1 链变成"随时暴击 +12.5%"丢失节奏感。实装时把暴击 buff 改为"攻击解离目标时附带"的条件式 buff。

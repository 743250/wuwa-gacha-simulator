## 2. 官方资料分析 · 读懂官方想让她做什么

西格莉卡是 3.2 限定 S 级主 C，设计师给她一个核心定位：**编程语义（红/蓝/黄三种符文）→ 消耗符文组合释放「我即语义」爆发**。她像一个编程语言解释器：普攻/技能写入同语义代码，消耗时根据组合产生不同效果。

### 技能逐条读懂

- **语义系统**：普攻编红、技能编蓝、重击编黄—每种最多3层，消耗所有语义释放凝语
- **「天赋？」叠层**：核心增伤资源，消耗符文时消耗30点日灵能量获得1层，上限3层（3链4层）。每层给伤害加深+无视防御（6链大幅强化）
- **日灵能量**：符文消耗时的追加资源，≥30点时消耗可提升伤害并叠天赋层
- **我即语义**：核心爆发招，消耗全部4枚符文触发大量衍射伤害

### 一句话灵魂锁定

> **西格莉卡是"普攻/技能/重击编三种语义 → 消耗全部释放我即语义爆发"的衍射主C。爽点在于管理三种语义的搭配组合，在关键时刻用正确的符文组合打出最大收益的「我即语义」。**

## 3. 模拟器取舍设计

### 设计思路：三种语义积累 → 凝语释放

模拟器没有「解读状态/句点/日灵能量/天赋？」等多层资源系统，但**三种语义分别积累→消耗全部语义释放凝语**这条核心算法用 3 种 FORTE 存天然可以表达。语义资源上限各 3 层（红/蓝/黄分别对应普攻/技能/重击），消耗时每种颜色 atk × 120%，全色齐全额外 +200%。

### 玩家循环节奏

1. 西格莉卡上场，普攻 +1 红 / 技能 +1 蓝 / 重击 +1 黄
2. 三种语义各至少 1 层时 → 施放「凝语」消耗全部语义爆发
3. 理想循环：普攻→技能→重击→凝语（消耗3色齐全→全色额外+200%）
4. 共鸣解放作为纯伤害爆发，变奏快速入场

### 保留的核心

1. **三种语义积累**：红（普攻+1）/ 蓝（技能+1）/ 黄（重击+1），每种最多 3 层
2. **凝语释放**：消耗全部语义，每种 atk × 120%，全色齐全额外 +200%
3. **共鸣技能**：罗伊近身格斗技，atk × 180% +1 蓝
4. **共鸣解放**：如那期望般！主 atk × 400% / 副 atk × 200%

### 舍弃/合并清单

| 官方机制 | 模拟器处理 | 理由 |
|---|---|---|
| 解读状态 / 专注 / 回声 | 不做 | 多层状态机超出工厂级别 |
| 句点 | 不做 | 独立资源系统 |
| 日灵能量 | 不做 | 符文消耗的追加资源 |
| 「天赋？」叠层 | 6 链折算为凝语伤害加深 | 叠层逻辑简化 |
| 我即语义符语爆破/链刃/日组合 | 合并为凝语单招 | 组合派生属 ACT 维度 |
| 语义的祝福（声骸技能团队联动） | 不做 | 跟技逻辑 |
| 凝语（奏技能附加） | 不做 | 延奏系统暂未实装 |
| 声骸技能触发类效果（4链） | 折算为共鸣回路触发 | 模拟器无骸技能伤害类型 |

## 7. 设计边界（bug 防范点）

1. **语义上限 3 层不溢出**：每次获得语义时检查是否已达上限，已达上限则不增加——避免普攻满红后再普攻吞层
2. **凝语只释放一次**：凝语消耗全部语义后立即清空 3 种语义至 0，不残留——避免同回合内多次触发
3. **全色齐全判**：凝语施放时检查 3 种语义是否都 ≥1 层，是则触发额外 +200% 伤害；消耗 3 种语义时按各颜色的当前层数独立计算 atk × 120%/层——不因全色额外倍率而忽略多层的各色倍率
4. **重击 CD 1 回合**：重击是黄语义唯一入口，CD 1 限制每 2 回合只能叠 1 层黄语义——平衡语义积累节奏
5. **4 链全队 buff 跟随全队**：攻击 +20% 是全队 buff，切人保留，持续 2 回合
6. **6 链「天赋？」无视防御不与同类效果叠加**：6 链无视防御效果不与武器/其他角色的无视防御线性叠加，取最高值

### 切人保留边界

7. **语义跟随西格莉卡本人**：3 种语义是个人资源，切人时数值保留不清零
8. **3 链「天赋？」切人不消除**：3 链激活时「天赋？」层数不因切换角色而清除（但自然持续结束时仍清空）
9. **4 链全队 buff 切人保留**：全队攻击 +20% 不因切人丢失

## 8. 留给讨论的开放问题

1. **HP/ATK ≈ 24.6× 却按 ATK 核设计**：西格莉卡 JSON 源记录 HP 10775 / ATK 438，比例远超 HP 核线，但官方技能无生命倍率。倾向保留 ATK 核——模拟器不重新设计倍率基线；若实装后输出偏低可上调为普攻 atk × 110% / 技能 atk × 200%。
2. **三种语义分别 3 层，凝语消耗全部——高层数时倍率是否过高**：满 3 层×3 色时凝语总倍率 = 3×120% + 200% + 6 链加成 ≈ 800%。倾向保留——这是每 3 回合一次的资源爆发，2 AP 成本合理；若实装后循环过强可降为全色额外 +150%。
3. **重击唯一黄语义入口是否让节奏太慢**：黄语义需要每 2 回合按一次重击（CD 1），打乱普攻→技能的流畅节奏。倾向保留——重击 2 AP 成本与黄语义的爆发收益匹配；若玩家反馈节奏卡手可改为普攻第 3 段自动 +1 黄语义。
4. **语义「未实装声骸技能」效果折算**：4 链官方是"施放声骸技能时全队攻击+20%"，模拟器折算为"施放凝语时全队攻击+20%"。倾向保留折算——凝语是西格莉卡的核心爆发招，作为触发条件最自然。

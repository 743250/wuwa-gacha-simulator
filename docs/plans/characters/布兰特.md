## 2. 官方资料分析 · 读懂官方想让他做什么

布兰特是鸣潮首位限定 5★ 热熔治疗辅助，集治疗、护盾、群体增益于一身。设计师给他一个核心定位：**攒满航路、释放火焰归亡曲，一套动作同时完成治疗全队与AOE输出**。他不需要像传统辅助那样躲在后台——他必须在场上持续攻击积攒航路，用空中攻击的灵活派生完成资源循环，再用火焰归亡曲把积累的资源一次性兑现为团队收益。

### 技能逐条读懂

- **航路（喝彩）**：资源槽 0-100，常态攻击（每击+8）、共鸣技能（+18）、共鸣解放（+25）命中时填充。满时共鸣解放替换为高伤害 + 全队治疗 + 护盾的火焰归亡曲。这是布兰特所有价值的载体——没有航路就没有治疗，没有航路就没有爆发。
- **空中攻击派生**：官方给布兰特设计了丰富的空中动作链——钩索冲荡、空翻重置闪避、空中重击狂想即兴。这是动作ACT的操作趣味，回合制下抽象为「重击·狂想即兴积攒航路」这一单一动作。
- **变奏技能 · 为我！**：入场时攻击目标并获得幕间掌声效果（下一次空中攻击从第2段开始）。模拟器中抽象为「变奏入场时获得 3 层乘风」——一个每层 +20% 伤害、满层 +60% 的增益。
- **延奏技能 · 航向确定！**：下一位登场角色热熔伤害加深 20%、共鸣技能伤害加深 25%，14 秒窗口，但切换提前结束。这是布兰特作为辅助的核心团队贡献——退场时给队友加 buff，让主C享受增益。
- **固有技能 · 迎海投火的决意**：空中攻击抗打断 + 热熔伤害加成 15%。这是数值层面的补强。

### 一句话灵魂锁定

> **布兰特是"攒满航路、烧尽舞台"的热熔辅助——在场上持续攻击积攒资源，用火焰归亡曲一次性兑现全队治疗与AOE爆发，退场时用延奏给队友铺好输出窗口。他的爽点不在于站场打满伤害，而在于"航路攒满的那一刻，按下解放既奶全队又炸全场"的掌控感。**

## 3. 模拟器取舍设计

### 设计思路：航路是布兰特全部价值的计速器

模拟器没有动作游戏的"站位 / 钩索冲荡 / 空翻 / 空中派生"维度，但**资源条**这个核心是回合制天然能表达的——"积攒资源→满时解放获得额外收益"在 AP 回合制里是标准的资源管理模型。所以布兰特在模拟器里比动作版更纯粹：所有原本靠"空翻节奏 / 钩索落点 / 空中派生选择"塑造的细节全部合并到「航路积攒→满时火焰归亡曲强化」这一件事里，让一个资源条串联起他的全部动作价值。

### 玩家循环节奏

```
变奏入场 → 获得 3 层乘风（伤害 +60%）→ 普攻/技能攒航路 → 航路满 → 共鸣解放·火焰归亡曲（伤害 x1.6 + 全队治疗）→ 切主C 享用延奏 buff 爆发输出（2 链延奏爆炸）
```

### 保留的核心

1. **航路资源条**：通过常态攻击、共鸣技能、共鸣解放积攒，满时共鸣解放替换为强化版火焰归亡曲——伤害 x1.6 + 全队治疗 atk x 150%
2. **乘风**：变奏入场时获得 3 层增益，每层 +20% 伤害，满层 +60%
3. **火焰归亡曲全队治疗**：满航路时的解放附加全队治疗（atk x 1.5 x 治疗加成）
4. **延奏·航向确定！**：下一位登场角色热熔伤害加深 20%、共鸣技能伤害加深 25%
5. **共鸣链强化核心循环**：所有链条在航路-火焰归亡曲这一主轴上叠加增益

### 舍弃/合并清单

| 官方机制 | 模拟器处理 | 理由 |
|---|---|---|
| 空中攻击 4 段 + 钩索冲荡 + 空翻重置闪避 | 合并为「重击·狂想即兴」积攒航路 | 动作 ACT 操作维度，回合制无空中节奏表达 |
| 变奏·幕间掌声（从第 2 段开始空中攻击） | 合并为「变奏获得 3 层乘风」 | 回合制无攻击段数起始控制 |
| 燃焰状态（常态攻击/技能积攒效率翻倍） | 不做 | 模拟器航路积攒已有固定增益参数，无"效率翻倍"状态窗口 |
| 火焰归亡曲护盾（切换不继承） | 不做 | 护盾系统暂未实装；护盾量 +20% 并入 4 链全队治疗 |
| 共鸣效率转攻击（戏中人生 / 「我」的人生） | 不做 | 共鸣效率作为乘区在模拟器战斗中未实装；攻击数值由面板直接计算 |
| 涛声喝彩四段阈值治疗（25/50/75/100） | 合并为满航路一次性治疗 | 回合制无四段阈值触发场景 |
| 固有技能·领航之焰（治疗量 +20%） | 不做 | 治疗系数固化在 brantFlameDirge 的 atk x 1.5 公式中 |
| 固有技能·迎海投火的决意（空中抗打断 + 热熔伤害加成） | 不做 | 抗打断无对应机制；热熔伤害加成为面板参数，由基础数值体现 |
| 2 链延奏爆炸的"每秒可触发 1 次" | 合并为"每回合可触发 1 次" | 回合制时间折算 |
| 4 链共鸣效率转治疗（每 1% = 6.60 HP） | 简化为治疗加成 +25% | 共鸣效率未实装，改用固定治疗系数 |
| 巧手烹调 | 不做 | 与战斗无关 |

### 各招式完整文字描述

**普攻**：对主目标造成 atk x 100% 热熔伤害，消耗 1 AP，无 CD。每击积攒 8 点航路。布兰特的普攻是航路积攒的基础手段，也是他"在场上不能闲着"的底层逻辑——每次平砍都在为下一次火焰归亡曲做准备。

**重击·狂想即兴**：布兰特消耗耐力进行空中重击，造成 atk x 220% 热熔伤害，消耗 2 AP，CD 1 回合。这是空中攻击的浓缩表达——替代了官方复杂的四段空中连段与钩索冲荡。积攒航路，可配合变奏入场的 3 层乘风打出高额伤害。

**共鸣技能·起锚！**：布兰特将自己弹飞至空中，对范围内目标造成 atk x 180% 热熔伤害，消耗 1 AP，CD 3 回合。积攒 18 点航路，是航路积攒效率最高的动作。作为循环节奏的节拍器——每 3 回合打一次技能保证航路稳步上升。

**共鸣解放·火焰归亡曲**：航路满时，共鸣解放替换为火焰归亡曲。对主目标造成 atk x 400% 热熔伤害（满航路时伤害 x1.6 = 640%），同时为全队所有存活角色回复生命值（基础值 = 布兰特攻击力 x 150%，受治疗加成影响）。消耗 3 AP，积攒 25 点航路。6 链时解放后触发再燃——额外一次等同于火焰归亡曲 30% 的热熔伤害（普攻伤害类型）。这是布兰特全部价值的兑现瞬间———奶全队、炸全场、一条资源条换一个攻防一体的回合。

**变奏技能·为我！**：布兰特入场时攻击目标，获得 3 层乘风（每层 +20% 伤害，满层 +60%）。不带独立伤害数值——变奏的意义不在于打那一下，而在于启动完整的循环节奏。

**延奏技能·航向确定！**：布兰特退场时，下一位登场角色获得热熔伤害加深 20%、共鸣技能伤害加深 25%，持续 2 回合（切人提前结束）。2 链时延奏获得额外效果：下一位角色施放共鸣技能命中目标时，布兰特造成一次 atk x 440% 的热熔爆炸（普攻伤害类型），每回合可触发 1 次，最多 2 次。这是布兰特作为辅助的团队贡献输出——退场不算完，下一人还在享受他的增益。

## 5. 共鸣链 · 模拟器版完整设计

### 1 链 · 跟随洋流和信风

施放变奏技能为我！或每次空中攻击时，布兰特造成的伤害提升 20%，持续 2 回合，可叠加 3 层。满层时伤害提升 60%。这条链奖励玩家以变奏起手开始循环，把入场到攒满航路之间的填充动作也变成有价值的伤害窗口。

### 2 链 · 掠夺欢声与笑颜

施放空中攻击和火焰归亡曲时，布兰特暴击提升 30%。同时布兰特的延奏技能航向确定！获得额外效果：下一位登场角色施放共鸣技能命中目标时，布兰特将召唤一次爆炸，造成布兰特攻击 440% 的热熔伤害（普攻伤害类型）。爆炸每回合可触发 1 次，最多可触发 2 次。切换至其他角色不会清除该额外效果的剩余次数。这条链把布兰特从纯粹的辅助升级为"退场后还能打两拳"的延奏爆发支点。

### 3 链 · 无惧惊涛骇浪

火焰归亡曲造成的伤害倍率提升 42%。这是一条纯粹的伤害链——直接拔高核心技能的爆发数值，让满航路解放的回报更丰厚。

### 4 链 · 纵情放声歌唱

火焰归亡曲为全队提供的治疗量提升 25%。布兰特施放火焰归亡曲时，额外为全队回复生命值。这条链把布兰特抬入可靠治疗者的行列——每次解放都附带一个群体抬血，让队伍在长期战斗中保持健康血线。

### 5 链 · 演员说：生活皆舞台

布兰特造成普攻伤害时，普攻伤害加成提升 15%，持续 2 回合。作为填充动作的补偿，让常态攻击在航路积攒之外多一层回报。数值克制，不喧宾夺主。

### 6 链 · 船长答：狂欢即世界！

空中攻击造成的伤害倍率提升 30%。施放火焰归亡曲后，会在原地产生一次再燃，造成等同于火焰归亡曲 30% 的热熔伤害（普攻伤害类型）。再燃是这条链的灵魂——一次解放打出两段伤害，把火焰归亡曲的单次爆发升级为双段输出。同时航路满时的火焰归亡曲额外获得强化倍率提升（基础 x1.6 提升至 x2.0），让满资源解放的含金量达到顶峰。

## 7. 设计边界（bug 防范点）

1. **航路只在布兰特本人动作时积攒**：gainPerNormal/Skill/Burst 只在布兰特执行对应动作时触发，不因队友动作或被动效果而意外积攒。

2. **乘风只从变奏获得，上限 3 层**：brantGainWindRide 每次 +1 层，上限 3 层。层数在布兰特身上持久保存（切换到后台不清零），回到场上时继续生效。每层独立计算 +20% 伤害乘区。

3. **满航路才触发火焰归亡曲全队治疗**：FORTE['布兰特'].ready 为 true 时才进入治疗分支。不满航路时解放只打伤害不给治疗——防止玩家为了贪治疗故意不满资源放解放。

4. **火焰归亡曲治疗基于布兰特的攻击力**：公式 atk x 1.5 x (1 + healBonus)，healBonus 仅来自 chain 4（+25%）等渠道。治疗量不随队友属性变化，布兰特不在场时治疗以他的属性为基准。

5. **6 链再燃不独立触发，附着于火焰归亡曲之后**：brantReignitePending 标记设为 true，由后续攻击动作消耗（而非自动独立触发）。再燃伤害 = 火焰归亡曲伤害 x 30%，类型为普攻伤害——与原官方描述一致。

6. **FORTE_BOOST 仅 6 链生效**：FORTE_BOOST['布兰特'] = { atChain: 6, bonus: 0.4 } 只在 chain 6 激活时把航路满时火焰归亡曲的倍率从 x1.6 提升至 x2.0。低于 6 链时不触发此项加成。

7. **2 链延奏爆炸遵循回合计数**：爆炸每回合可触发 1 次，最多 2 次。爆炸次数计数器在切换角色时不归零（与官方描述"切换后保留"一致）。

### 切人保留边界

1. **航路积攒进度跟随布兰特本人**：航路数值是布兰特的个人状态，切人时保留，回场时继续。不因队友在场而自动增长或衰减。

2. **乘风层数持久保留**：3 层乘风的层数在布兰特身上持久存在，不因切换至其他角色而消失。布兰特再次登场时层数仍在。

3. **2 链延奏爆炸次数切换后保留**：爆炸的剩余可触发次数在切换角色时不归零——符合官方"切换至其他角色会保留该额外效果"的设计。

4. **延奏 buff 不随布兰特本人切回而延续**：延奏·航向确定！施加给下一位登场角色后，若再次切回布兰特则 buff 提前结束——官方明确"若切换至其他角色则该效果提前结束"，布兰特本人不算"其他角色"；但游戏实际行为是切走即消失，模拟器遵循此规则。

## 8. 留给讨论的开放问题

1. **火焰归亡曲治疗系数**：当前 atk x 1.5 x (1 + healBonus)。以布兰特 375 基础攻击、约 1500-1800 实际攻击计算，单次治疗约 2250-2700，全队 3 人合计 6750-8100。倾向保留此系数——这是辅助身份的核心厚度，过低的治疗会让玩家觉得"按了解放还是得切治疗"；若实装后团队续航过剩可下调至 atk x 1.2，但优先不动。

2. **2 链延奏爆炸的回合触发限制**：当前设计为"每回合 1 次，最多 2 次"。2 链爆炸在回合制下可能触发窗口太窄（主 C 打完技能后布兰特不在场，爆炸自动触发）。倾向保留——这是辅助退场后贡献的合理上限；若实装后触发频率过低可改为"最多 3 次"，但优先不动。

3. **6 链再燃的伤害类型**：再燃归类为普攻伤害（normal type），与 registry 效果一致。考虑再燃是否应随火焰归亡曲的强化倍率同步缩放——当前再燃为火焰归亡曲 30%，而归亡曲本身受 chain 3（+42%）和 FORTE_BOOST 影响。倾向保留当前设计（再燃取基础归亡曲的 30%，不参与二次倍率叠加），防止伤害链失控。

4. **空中攻击与重击的关系**：空中攻击的多段派生在模拟器中合并为「重击·狂想即兴」一个动作。当前重击积攒的航路量未单独设定（跟随标准普攻/技能积攒）。如后续需要调优空中攻击的航路获取效率，可独立设定 gainPerHeavy 参数，但目前优先保持与代码一致。

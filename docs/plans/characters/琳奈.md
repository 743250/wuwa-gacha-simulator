### 技能完整描述（官方原文搬运）

**常态攻击 · 泛彩流光**：普攻短按或长按施放普攻，进行最多3段的连续攻击，造成衍射伤害。空中攻击消耗耐力进行空中下落攻击，造成衍射伤害。闪避反击成功闪避后一定时间内短按普攻，将会攻击目标，造成衍射伤害。普攻·灵感碰撞处于「光学取样」阶段时，如果【溢彩】已满，按住普攻进入蓄力状态。蓄力期间，每0.2秒将15点【溢彩】转换为12.5%的【流光】，蓄力期间免疫打断且受到伤害降低50%。松开普攻或【流光】满时，琳奈将根据当前转换的【流光】百分比造成衍射伤害。绮彩巡游·普攻绮彩巡游状态期间，普攻替换为绮彩巡游。

**共鸣技能 · 琳奈式创想**：短按共鸣技能，造成衍射伤害。处于绮彩巡游状态时长按共鸣技能，造成衍射伤害，并退出绮彩巡游状态。施放该技能后一定时间内短按普攻将会施放普攻第2段。琳奈式创想与加色混合共享冷却时间。加色混合绮彩巡游状态期间，处于地面时，短按共鸣技能，造成衍射伤害。琳奈式创想与加色混合共享冷却时间。

**共鸣解放 · 爆炸喷涂**：造成衍射伤害。施放时使附近队伍中所有角色造成的伤害提升24%，持续30秒。普攻·向着多彩的明天！施放共鸣解放·爆炸喷涂一定时间内，短按普攻，可以施放普攻·向着多彩的明天！，造成衍射伤害。

**固有技能 · 永不褪色！**：施放普攻·视觉冲击后，琳奈会在地面留下颜料。处于颜料内的目标会被持续附加光致变染，每2秒触发一次，持续5秒。颜料存在时，切换共鸣模态不会影响该光致变染的附加效果。琳奈处于队伍中时，科考摩托的动能储备上限提升600点。

**固有技能 · 《自适应光学在生活中的实际应用》**：施放变奏技能·来点儿颜色瞧瞧时，9秒内自身的衍射伤害加成提升25%。绮彩巡游状态期间，若琳奈不处于战斗状态，施放地面后闪时会为自身附加光学迷彩。拥有光学迷彩时，琳奈进入目标的警戒范围将不会进入战斗状态。

**变奏技能 · 来点儿颜色瞧瞧！**：造成衍射伤害，命中时为目标附加光致变染。施放时，如果处于「光学取样」阶段，回复100点【溢彩】。

**共鸣回路 · 色光混合律**：「光学取样」阶段琳奈初始处于「光学取样」阶段。施放特定技能期间回复【溢彩】。绮彩巡游琳奈施放普攻·灵感碰撞时，进入绮彩巡游状态。绮彩巡游状态期间，会持续回复【流光】。普攻·幻光折跃绮彩巡游状态期间，至少拥有1/3【流光】上限时，跳跃替换为普攻·幻光折跃。消耗1/3最大【流光】，造成衍射伤害，命中时为目标附加光致变染。

**固有技能 · 巧手烹调**：当前角色烹饪时有概率产出特色料理。

**延奏技能 · 有空一起兜风！**：造成100%的衍射伤害。下一个登场的角色全伤害加深15%，共鸣解放伤害加深25%，持续14秒，若切换至其他角色则该效果提前结束。施放延奏技能时，退出绮彩巡游状态。

## 2. 官方资料分析 · 读懂官方想让她做什么

### 技能逐条读懂

- **常态攻击·泛彩流光**：三段普攻+空中下落+闪避反击。核心是「溢彩→流光」的蓄力转换：溢彩满后按住普攻，每0.2秒把15溢彩转12.5%流光，松手按流光百分比打衍射伤害。这是设计师给琳奈的核心爆发节奏。
- **共鸣技能·琳奈式创想**：地面短按是普通技能；绮彩巡游状态下长按则打伤害并主动退出巡游。加色混合是巡游期间的地面变体，与创想共享CD——玩家要在两种普攻派生间做选择。
- **共鸣解放·爆炸喷涂**：AOE衍射+全队伤害+24%（30秒），后续短按普攻派生「向着多彩的明天」。既是爆发也是团队增益。
- **固有·永不褪色！**：普攻·视觉冲击后地面留颜料，内里的目标持续挂光致变染（每2秒，5秒）。颜料不因模态切换消失——给琳奈一个"地面区域"持续压制力。
- **固有·自适应光学**：变奏后9秒自身衍射+25%；巡游状态非战闪避附光学迷彩，进怪警戒圈不触发战斗。探索层机制，战斗层主要用衍射+25%。
- **变奏·来点儿颜色瞧瞧**：入场伤害+挂光致变染+光学取样阶段回100溢彩。变奏是快速进状态的起手。
- **共鸣回路·色光混合律**：双资源条——溢彩（取样阶段技能回）和流光（巡游期间持续回）。绮彩巡游+幻光折跃是巡游期间的位移攻击派生，消耗1/3流光，命中挂光致变染。
- **延奏·有空一起兜风！**：退场全伤害+15%、解放伤+25%（14秒），切人提前结束。是副C定位的核心——下场也提供持续增益。

## 3. 模拟器取舍设计

### 设计思路：溢彩/流光双资源 + 绮彩巡游状态机

琳奈在模拟器中的核心是双资源条 + 双形态。A级工厂下「光学取样」和「绮彩巡游」两个阶段统一为一套招式组，但通过资源状态弹出"重击替换"的逻辑——溢彩满后重击替换为灵感碰撞蓄力。巡游状态作为入场后或变奏后的强化窗口，期间普攻/技能的派生走"轮滑射击"路径。重击（重击型）作为蓄力爆发的载体保留。

### 玩家循环节奏

1. 起手变奏入场 → 挂光致变染 + 回100溢彩 + 自身衍射+25%
2. 普攻/技能积累溢彩，进入「灵感碰撞」可施放状态
3. 溢彩满时施放重击（灵感碰撞）蓄力 → 转换流光 → 松手按流光百分比打出爆发
4. 共鸣解放·爆炸喷涂打AOE爆发 + 全队伤害+24%
5. 巡游状态下幻光折跃/加色混合持续输出+挂光致变染
6. 延奏退场给下个登场角色全伤害+15%、解放+25%

### 保留的核心

1. **溢彩/流光双资源**：溢彩积累满→重击蓄力转流光→按比例爆发
2. **绮彩巡游状态**：入场或变奏触发，期间持续回流光+派生轮滑攻击
3. **灵感碰撞蓄力重击**：核心爆发手段，倍率与流光百分比挂钩
4. **延奏副C增益**：退场给下个登场角色多层伤害加深
5. **光致变染**：颜料区域持续附加，挂给目标的标记状态

### 舍弃/合并清单

| 官方机制 | 模拟器处理 | 理由 |
|---|---|---|
| 三段普攻/空中下落/闪避反击 | 统一为普攻一段，倍率与 official 三段持平 | 回合制无段间派生操作 |
| 蓄力期间免疫打断/受伤-50% | 合并入重击动作，模拟器无打断系统 | 无相关判定 |
| 绮彩巡游+幻光折跃+轮滑移动 | 巡游状态用 buff 表示，期间普攻派生幻光折跃（额外伤害） | 移动机制无回合制对应 |
| 颜料地面区域+牵引 | 简化为重击附加"光致变染"标记（2回合持续伤害），1链牵引合并为额外每回合伤害 | 地面区域在回合制下无空间概念 |
| 预调色25层叠加 | 简化为3层预调色，每层+15%加色混合伤害 | 多层细粒度在回合制下过于繁琐 |
| 心之彩3层 | 保留3层，每层让目标受虹彩飞溅/视觉冲击+30% | 核心质变链效果保留 |
| 巧手烹调 | 不做 | 与战斗无关 |
| 科考摩托/光学迷彩/探索机制 | 不做 | 非战斗层 |

### 4链 · 灰影随风呼啸而去

攻击提升20%。

### 5链 · 不羁未来的映想

共鸣解放·爆炸喷涂倍率+70%（叠层）。

### 6链 · 以「我」为名的真彩

## 7. 设计边界（bug 防范点）

1. **溢彩满才能放灵感碰撞**：重击替换逻辑严格按 `furoloNotes >= 100` 判定，溢彩未满时重击按钮不可用。
2. **流光百分比→倍率映射线性**：满流光=4.0倍，半流光=2.0倍，零流光=0倍。禁止任何"最低保底倍率"以防溢彩蓄力逻辑被绕过。
3. **巡游状态切人消失**：延奏退场主动退出巡游；切人退场同样退巡游；防止巡游 buff 在场外长期挂留。
4. **预调色层数严格封顶3**：流光长期≥80时每回合+1，封顶3层；预调色不可继承到下次巡游。
5. **心之彩在解放/重击后立刻清零**：避免心之彩叠层影响自身爆发招式数值二次加成。
6. **溢彩/流光不回退**：消耗即清零，禁止"打折消耗"。
7. **延奏增益不可与2链叠加超过2层**：2链给下个登场角色+25%是叠层，叠层 cap=2 层即止；防止多层叠加爆表。
8. **6链流光上限360**：解锁6链后所有相关计算（幻光折跃消耗、转换公式）按新上限走。

### 切人保留边界

1. **溢彩角色专属保留**：下场保留数值，再次上场读取。
2. **流光角色专属保留**：同溢彩。
3. **巡游不保留**：下场即清，再次上场需重新展开。
4. **预调色不保留**：下场即清。
5. **心之彩绑定琳奈**：下场即清，再次上场不继承。
6. **光致变染绑定敌人**：切人不移除，持续伤害仍生效。

## 8. 留给讨论的开放问题

1. **HP/ATK 核类型**：琳奈HP/ATK = 32.6×，远超HP核判定线。 ATK 仅 375，灵感碰撞满流光 atk×400% 在副C位是否足够？若实装后伤害不足是否改 HP 核方案？
2. **溢彩蓄力节奏折算**：官方0.2秒转一次在实时游戏里是连续蓄力，模拟器折算为"溢彩满即重击=灵感碰撞"，是否丢失"蓄到一半松手也能放"的策略感？是否引入"半蓄力"中间档？
3. **预调色层数简化**：官方25层/55%每层，模拟器折算3层/15%每层，是否过简？是否保留"流光<120时每0.5秒失去1层"的回退机制？
4. **颜料地面区域的回合制化**：官方颜料是地面区域+牵引聚怪，模拟器简化为重击附加2回合持续伤害。1链"颜料持续+100%是否折算为持续伤害+2回合？还是保留区域概念？
5. **延奏双伤害加深叠层**：2链给下个登场角色+25%是叠层还是替换？若叠层 cap 应为多少层？
6. **6链流光上限360的战术意义**：翻3倍流光=3次灵感碰撞满流光爆发，是否过于强化"长战斗"曲线？是否考虑短战斗中加成是否过分？

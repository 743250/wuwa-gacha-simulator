## 2. 官方资料分析 · 读懂官方想让她做什么

卡提希娅是鸣潮首位限定5★ 气动迅刀主C。设计师给她一个核心定位：**叠决意开形态→叠风蚀效应打爆发的双形态循环**。她不像忌炎靠站场重击循环，也不像今汐靠协奏爆发——她的循环驱动来自一套高度自洽的资源系统：卡提希娅常态积累决意→解放进入芙露德莉斯形态→形态内积累风蚀效应→第二次解放结算风蚀爆发→回到常态重新循环。

### 技能逐条读懂

- **决意**：普攻/共鸣技能/重击积累，上限3 层，每层 +10%气动伤害，2回合衰减。这是进入芙露德莉斯形态的门票——3层决意提供异权（非大招技能双层风蚀）
- **芙露德莉斯形态**：共鸣解放「听骑士从心祈愿」切换，持续3回合。期间每次攻击/技能附加风蚀效应并回复额外能量。形态是她的输出窗口核心
- **风蚀效应**：气动通用 debuff，每层 +10%气动伤害（通用加深）。芙露德莉斯形态下的第二次解放按每层 +20%独立倍率加成，清空全部风蚀退出形态
- **人权/神权/异权**：三种形态之力，根据消耗决意层数获得——1层人权（减伤30%），2层神权（暴击率+25%），3层异权（非大招技能双层风蚀）

链的排布逻辑：1-2 链加厚循环中积累风蚀的途径，3 链拉升爆发天花板，4 链把单人爆发延伸到全队增益，5 链提供生存容错，6 链让风蚀从消耗品变为可持续资源。**所有链都围绕“双形态叠风蚀→爆发”这一个核心调整参数**——没有任何一条链试图改变她的循环节奏，所有加成都在“更快积累/更高爆发/更稳生存”上做加法。

### 一句话灵魂锁定

> **卡提希娅是“叠决意开形态→叠风蚀效应打爆发的双形态主C”——常态蓄决意换形态，形态内叠风蚀效应，第二次解放结算全部风蚀打出毁灭性爆发。她的爽点在于“叠了三层决意开的那一刻，你知道接下来每一击都在为最后的核爆做准备”.**

## 3. 模拟器取舍设计

### 设计思路：决意与风蚀的双资源驱动

模拟器没有动作游戏的“剑之影回收/空中连段/站位”等维度，但**决意叠层→形态切换→风蚀积累→爆发结算**这套资源循环是回合制天然能表达的——积累资源→切换状态→在状态窗口内积累第二种资源→一次性结算在 AP 回合制里是成熟的双资源模型。所以卡提希娅在模拟器里保留了最纯粹的双形态循环：常态用普攻/技能叠决意，换形态叠风蚀，攒够后一个解放打出爆炸伤害，回到常态重新循环。

### HP 核倍率校准

卡提希娅是 HP 核角色，所有伤害以最大生命为基数计算。HP(14800) / ATK(312) ≈ 47.4×，倍率已相应下调：

- 普攻：HP × 12%（以 ATK 视角约 ATK × 569%）
- 共鸣技能：HP × 22%（以 ATK 视角约 ATK × 1043%）
- 重击：HP × 26%（以 ATK 视角约 ATK × 1233%）
- 共鸣解放·看潮怒风哮之刃：HP × 46.2%（以 ATK 视角约 ATK × 2190%）

基线倍率确保“普攻不会反超解放”：解放倍率是普攻的约3.85倍，配合风蚀每层 +20%，5层时约7.7倍，符合“大招是伤害顶点”的回合制直觉。

### 保留的核心

1. **决意系统**：普攻/共鸣技能/重击积累，上限3 层，每层气动伤害 +10%，2回合衰减。满层进入芙露德莉斯形态时获得最强形态之力（异权）
2. **芙露德莉斯形态**：共鸣解放进入，持续3回合，期间攻击/技能叠风蚀、额外回能；形态内可施放第二次解放·看潮怒风哮之刃，结算全部风蚀爆炸伤害后退出形态
3. **人权/神权/异权**：三种形态之力，根据消耗决意层数提供减伤/暴击/双层风蚀
4. **共鸣链加厚双形态循环**：1 链破韧给风蚀、2 链变奏给风蚀、3 链爆发倍率提升、4 链全队元素增伤、5 链生存容错、6 链风蚀层数翻倍不清空

### 舍弃/合并清单

|---|---|---|
| 神权剑之影/异权剑之影/人权剑之影三种召唤物 | 不做 | 召唤物属动作 ACT 维度，回合制无对应 |
| 剑之影回收减少技能 CD | 不做 | 回合制 CD 是回合数，无“回收”交互 |

## 7. 边界条件与异常处理

### 7.1 决意衰减时机

决意每层独立2回合衰减，获得新层时刷新全部层数的持续时间。在 state machine 中，决意衰减通过 `cartethyiaResolveDecay` 回合结束钩子检查——需要注意当芙露德莉斯形态结束时切回卡提希娅，必须检查决意层数是否已归零。边界情况：如果在衰减前最后一回合进入了芙露德莉斯形态，形态期间决意不消耗但计时器仍在走，**形态结束回到卡提希娅时可能瞬间触发衰减**，导致预期外的资源丢失。

### 7.2 形态回合计数

芙露德莉斯形态持续3回合。计入回合的方式：进入形态的当前回合计为第1回合，形态结束于第3回合结束时。`cartethyiaFurTurns` 在实际战斗引擎中需注意：切换角色不会减少形态剩余回合数？——否，回合制下切人经过1AP即消耗1回合。这是 `carryOnSwitch` 属性控制——`carryOnSwitch: true` 的含义是 state machine 在角色切换时保留，而非在回合引擎中保留。如果 state machine 仅靠 `onTurnEnd` 递减计数，而角色被切下时不会被调用，则形态可能永不结束。**必须确保形态计数同时绑定回合引擎和角色上场事件**

### 7.3 切换时 state machine 清理

`carryOnSwitch: true` 意味着角色切下场时 state machine 不重置。 但 `resolveBurstCost` 等资源变量必须在角色上场时正确初始化。具体边界：
- 卡提希娅下场时决意层数保留，芙露德莉斯形态保留，风蚀效应是目标 debuff 自然保留。
- 卡提希娅上场时 `cartethyiaState` 恢复最近状态， `cartethyiaFurTurns` 如有余值则继续递减。
- 如果上场时 `cartethyiaFurTurns > 0` 但场上已无风蚀层数（队友消耗或目标死亡后新目标不继承），进入“空形态”状态——解放按钮文案仍是“看潮怒风哮之刃”但无风蚀加成，释放后只有基础倍率。这是合理的设计边界，不需要额外引导。

### 7.4 0AP 解放边界

第一次解放·听骑士从心祈愿消耗0AP。这意味着在AP为0时仍然可以释放第一次解放。`resolveBurstCost` 在 state machine 中返回0给第一次解放，但战斗引擎的AP检查逻辑需明确区分：AP检查在角色操作前，而第一次解放的AP消耗=0不应阻止释放。边界情况：当队伍所有角色AP耗尽时，可以通过第一次解放（0AP）来衔接回合。如果战斗引擎因AP=0完全禁用解放按钮，则第一次解放将永远无法在AP不足时释放。**战斗引擎必须对 `resolveBurstCost` 返回0的解放做特例处理——当回合的指令按钮不因AP不足而禁用0AP指令**

### 7.5 6链不清空与DoT交互

6链使看潮怒风哮之刃不清空风蚀层数。但风蚀效应的DoT（每回合结束时造成伤害）在回合结束时会检查层数。如果不清空且层数仍然存在，DoT仍然会触发——但DoT伤害基于风蚀效应自身的公式（敌人攻击力×层数×0.3），与卡提希娅的爆发伤害无关。**6链的“不清空”扩展了风蚀的DoT持续期，这可能导致DoT在非卡提希娅回合造成额外伤害**。这是合理的设计决策——6链价值本身就包含了“不必重新叠层”的优势。无需额外处理。

### 7.6 4链Buff去重

4链（为拯救舍弃其身）在附加风蚀时全队元素伤害+20%，持续2回合。同一敌人受到多次附加风蚀时，**不应叠加持续时间也不应产生多层同源buff**。如果在 combat hook 中对每次附加风蚀都无条件追加buff，则一次多段攻击可能触发3次全队增伤。实现建议：在 `applyChainBonuses` 中，4链效果使用唯一buff ID（`cartethyiaChain4`），已存在时仅刷新持续时间，不新建实例。

### 7.7 5链每场战斗标记

5链（将烈风重塑希望）的免死效果每场战斗仅触发1次。这需要持久化标记 `cartethyiaChain5Used`，在战斗开始时重置。边界情况：
- 跨波次战斗（如深塔多层）：从模拟器设计看，深塔每层是独立战斗，所以 **5链每层重置**。
- 如果角色在战斗中阵亡后复活：模拟器无角色复活机制，无需考虑。
- 5链触发后如果护盾被打破且角色再次受到致命伤害：护盾消失后应直接倒下（5链已消耗）。这是预期行为。

### 7.8 风蚀加成隔离

风蚀效应作为通用气动 debuff**不应与其他角色的类似效果产生数值冲突或重复计算**。具体来说：
- 卡提希娅的芙露德莉斯形态第二次解放按每层风蚀+20%伤害，这是卡提希娅专属的结算公式，而非风蚀效应 debuff 自身的属性。
- 其他气动角色（如漂泊者·气动）对风蚀效应的利用通过各自独立的公式计算，不应影响卡提希娅的爆发数值。
- 多个气动角色对同一目标叠加风蚀层数时，层数上限为6层，全队共享。卡提希娅的解放触发结算时不消耗其他角色附加的风蚀（6链不清空），其他角色的技能也不应意外消耗卡提希娅附加的风蚀。
- **实现建议**：风蚀效应层数作为目标属性（`target.erosionStacks`），各角色各自的结算公式只读取层数，不修改层数（除非明确设计为“消耗”）。层数增减统一走 `target.addErosionStack(n)` / `target.removeErosionStack(n)` 接口。

## 8. 待定与未决问题

### 8.1 形态内协奏结算

芙露德莉斯形态下，卡提希娅的变奏技能提供了协奏满时2倍倍率。但协奏满的判定——如果协奏在芙露德莉斯形态的回合中被填满，当前回合的变奏是否立即享受2倍？规则应明确：协奏满的判定在指令执行前快照，如果在同一次行动中协奏被填满（如普攻+变奏连续），变奏不触发2倍；需要在后续行动中切人再切回才会生效。这与守岸人的协奏规则一致。

### 8.2 人权/神权/异权与形态结束的特殊交互

当形态结束时（3回合耗尽），人权/神权/异权被清除。但如果形态在非自然结束时（如卡提希娅阵亡），三种形态之力是否应该在角色复活后重新拥有？模拟器无角色复活机制，暂不处理。如果未来加入复活机制，需补充规则：复活后形态之力不恢复，但决意层数保留（决意是角色属性而非形态属性）。

### 8.3 决意上限扩展的潜在设计空间

当前决意上限固定为3层。未来如果出现气动辅助角色可以提升决意上限的机制——如“队伍中气动角色上限+1”——卡提希娅的异权获取门槛（3层）是否应相应调整？目前暂不需要，待真实机制出现时再决定。
